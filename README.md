# Vault Classifier — local development foundations

This isolated macOS Swift package contains the source-only local foundations
for Vault Classifier. It deliberately does not change an existing product
version, installer, native-host registration, release build, central endpoint,
account system, or deployment.

Included now:

- A generic entry-evidence contract and validation limits, a checked seed
  taxonomy/model package, compact YouTube capability fixtures, and deterministic
  feature extraction.
- Sparse local scoring, decayed source priors, and named-policy decisions
  (`allow`, `dim`, `block`).
- A bounded FIFO local cache, decision/correction ledger, resource profiles,
  local seed-package backups, and a native SwiftUI development shell.
- A source-only Chrome/Edge YouTube adapter, authenticated native host, and
  app-owned local IPC; see [PHASE2.md](PHASE2.md). The bridge is disabled and
  unregistered until a future signed installer is explicitly authorized.
- Optional personal audit and local polishing: the user stores a Gemini key in
  this Mac's Keychain, enables a local token budget, queues a local candidate,
  and explicitly presses **Run Gemini**. The fixed adapter sends one bounded,
  non-streaming, non-stored request with no tools; quoted browser evidence is
  untrusted and the policy/leaf menu is generated by the app. Provider output
  cannot train the local model until the user explicitly confirms a currently
  policy-changing false allow. Local diagnostics are redacted before an
  explicit clipboard export.
- Verified package-lifecycle foundations: an Ed25519/checksum validator, private
  staging, activation, rollback, retention, and daily sync planning. An optional
  injected HTTPS client accepts only a fixed manifest/payload path and verifies
  a signed manifest before requesting its deterministic payload. Only a
  manifest-verified package capability can activate a coordinator.
- Explicit, bounded two-stage cache backfill after a verified activation. It
  first refreshes recent retained rows newest-first from direct evidence only,
  marking them provisional; it then rebuilds the source profile and final
  results FIFO oldest-first, so an entry cannot become its own source prior.
  Only the causal result is audit-eligible. No activation or backfill runs
  automatically.

The precise personal-audit and package-lifecycle contracts are in
[PHASE3-4.md](PHASE3-4.md).

Run the development shell with `./run-vault-classifier.sh` (or `swift run VaultClassifierApp`), or run verification with `swift test && swift build` from this folder.

No provider credential, audit evidence, configured server URL, or production
signing key is committed here. The app works locally with its bundled seed when
no optional provider feature is configured; the package client is not attached
to a scheduler, app setting, endpoint, or activation flow.
