# คู่มือผู้ใช้ Mac Vault

Mac Vault มีสามหน้า: **Vault** บล็อกแอปพื้นฐาน, **ตัวจัดประเภท** ติดแท็กเนื้อหาบนเบราว์เซอร์ที่รองรับ และ **Activity** แสดงการใช้งานที่บันทึกไว้ ส่วนขยายเบราว์เซอร์รวบรวมเนื้อหาที่รองรับและใช้การบล็อกในเบราว์เซอร์ ติดตั้งและเชื่อมต่อในเบราว์เซอร์ที่คุณใช้

## เริ่มต้นอย่างรวดเร็ว

1. ใน **Vault** เพิ่มกลุ่มการบล็อกและเป้าหมาย Apps แล้วเลือกแอปด้วยตัวเลือก +
2. เลือกลักษณะการบล็อกของกลุ่มและเปิดใช้
3. ใน **ตัวจัดประเภท** สร้างกลุ่ม เลือกแพลตฟอร์ม และเพิ่มแท็กพร้อมคำอธิบาย
4. เลือกระดับโมเดลในเครื่องและดาวน์โหลดหากจำเป็น เปิดใช้การติดแท็กในการตั้งค่าตัวจัดประเภท แล้วเปิดใช้กลุ่มอีกครั้ง
5. เปิดเนื้อหาที่รองรับในเบราว์เซอร์ที่เชื่อมต่อ หากต้องการให้แท็กควบคุมการบล็อก ให้ตั้งค่าตัวกรองแท็กในกลุ่มการบล็อกของเบราว์เซอร์

## กลุ่มการบล็อก

**กลุ่มการบล็อก** ใช้นโยบายการบล็อก ส่วน **กลุ่มตัวจัดประเภท** กำหนดแท็กให้เนื้อหา แต่ไม่ได้บล็อกสิ่งใดด้วยตัวเอง

1. เพิ่มกลุ่มการบล็อกและตั้งชื่อ
2. เลือกเป้าหมายใน **ใช้กับ**
3. เลือกเวลาที่จะใช้การบล็อก แล้วกำหนดตารางเวลาหรือเวลาที่อนุญาต
4. เปิดใช้กลุ่ม เป้าหมายทั้งหมดจะใช้นโยบายของกลุ่มร่วมกัน

การแก้ไขทั่วไปจะบันทึกโดยอัตโนมัติ หากมีข้อผิดพลาด แสดงว่าระบบไม่ยอมรับการแก้ไขนั้น ให้แก้ช่องดังกล่าวแล้วลองอีกครั้ง ปิดใช้กลุ่มเพื่อหยุดนโยบายโดยยังเก็บการตั้งค่าไว้ **ลบกลุ่ม** จะนำกลุ่มออก ลากกลุ่มเพื่อจัดลำดับใหม่ได้ หลายกลุ่มอาจมีผลกับเป้าหมายเดียวกัน การเลื่อนเวลาของกลุ่มหนึ่งไม่ได้ยกเลิกการบล็อกจากกลุ่มอื่น

**ส่งออก** จะคัดลอกการตั้งค่ากลุ่ม **นำเข้า** จะแทนที่การตั้งค่าของกลุ่มที่เลือกหลังจากยืนยัน

### เวลาที่อนุญาตและตารางเวลา

**บล็อกทันที** จะบล็อกเมื่อกลุ่มที่เปิดใช้อยู่ตรงกับเป้าหมายและอยู่ในช่วงตารางเวลาที่กำหนด **บล็อกเมื่อใช้เวลาที่อนุญาตหมดแล้ว** อนุญาตให้ใช้งานที่ตรงเงื่อนไขได้จนกว่าเวลาที่กำหนดจะหมด

กำหนดเวลาที่อนุญาตเป็นนาที และช่วงรีเซ็ตเป็นชั่วโมง ขีดจำกัดแบบเลื่อนนับการใช้งานภายในช่วงเวลาก่อนหน้าที่กำหนด การรีเซ็ตตอนเที่ยงคืนจะเริ่มรอบใหม่ ณ เที่ยงคืนตามเวลาท้องถิ่น รวมถึงขีดจำกัดแบบเลื่อนด้วย

เลือกวันในสัปดาห์ที่ต้องการให้ทำงาน และระบุช่วงเวลาท้องถิ่น (ไม่บังคับ) บรรทัดละหนึ่งช่วง เช่น **09:00-12:00** หากไม่ระบุช่วงเวลา จะใช้ตลอดวันที่เลือก ช่วงเวลาต้องสิ้นสุดหลังเวลาเริ่มในวันเดียวกัน หากต้องการคร่อมคืน ให้แยกกำหนดเป็นคนละวัน

### เลื่อนเวลา

ตั้งค่าการเลื่อนเวลาแยกกันในแต่ละกลุ่มการบล็อก **หยุดการบล็อกชั่วคราว** จะพักนโยบายของกลุ่มนั้นตามระยะเวลาที่กำหนด **เพิ่มเวลาที่อนุญาต** จะเพิ่มนาทีที่ใช้งานได้ให้กลุ่มที่จำกัดด้วยเวลา นับเฉพาะเวลาที่ใช้จากส่วนที่เพิ่มเป็นเวลาเลื่อน เวลาที่เพิ่มแต่ยังไม่ได้ใช้จะหมดอายุเมื่อรีเซ็ตครั้งถัดไป ส่วนขีดจำกัดแบบเลื่อนจะหมดอายุหลังครบหนึ่งช่วง หรือเร็วกว่านั้นตอนเที่ยงคืนหากเปิดตัวเลือกนี้

**ระยะหน่วงก่อนเริ่ม** จะเลื่อนการใช้การเลื่อนเวลาออกไป โดยการบล็อกยังดำเนินต่อ **ช่วงพักก่อนขอซ้ำ** คือเวลารอหลังการเลื่อนเวลาสิ้นสุดก่อนจะขอได้อีก **จำนวนครั้งที่ต้องยืนยัน** กำหนดจำนวนขั้นตอนยืนยัน จะใช้การเลื่อนเวลาในกลุ่มที่ตรึงไว้ได้ก็ต่อเมื่ออนุญาตไว้ก่อนตรึง

### ตรึงและ PIN

**ตรึง** จะป้องกันการแก้ไขทั่วไป การเลิกตรึงต้องยืนยันสิบครั้ง ห่างกันครั้งละห้าวินาที และต้องรอให้ครบเวลาที่ตั้งไว้พร้อมป้อน PIN หกหลัก **รอก่อนเลิกตรึง** ตั้งได้ตั้งแต่ 0–72 ชั่วโมง ค่า 0 คือไม่ต้องรอเพิ่ม

ขณะตรึงอยู่ สามารถเพิ่มเวลารอและเพิ่ม PIN ได้หากยังไม่มี จะลดความเข้มงวดของเงื่อนไขเหล่านี้ไม่ได้จนกว่าจะเลิกตรึงกลุ่ม การลบกลุ่มยังต้องรอให้พ้นเวลาที่เหลือและผ่าน PIN ด้วย

### กลุ่มที่เชื่อมโยงกัน

ใช้ **เชื่อมโยง** เพื่อเชื่อมกลุ่มที่เลือกไว้อย่างชัดเจนในโปรแกรม Vault อื่น กลุ่มที่เชื่อมโยงกันใช้ชื่อ การตั้งค่านโยบายที่รองรับ เป้าหมาย ปริมาณการใช้งาน และเงื่อนไขการตรึงร่วมกัน แต่ละโปรแกรมแก้ไขและบังคับใช้ประเภทเป้าหมายที่รองรับ ส่วนรายการเป้าหมายประเภทอื่นยังคงให้โปรแกรมที่เชื่อมโยงใช้งานได้ เมื่อยกเลิกการเชื่อมโยง กลุ่มและการตั้งค่าของแต่ละกลุ่มจะยังอยู่

หากสมาชิกที่เชื่อมโยงออฟไลน์ การแก้ไขอาจใช้ไม่ได้ ให้เปิด Mac Vault และเบราว์เซอร์ที่เชื่อมโยงเพื่อเชื่อมต่ออีกครั้ง นโยบายที่บันทึกไว้ในเครื่องอาจยังมีผลแม้สมาชิกออฟไลน์

## ขอความช่วยเหลือ

คลิก **i** ขนาดเล็กข้างช่องเพื่อดูคำอธิบาย คลิกด้านนอกหรือกด Escape เพื่อปิด รายการจะแสดงอยู่ในกรอบที่เลื่อนได้ ให้เลื่อนในกรอบเพื่อดูรายการเพิ่มเติม การค้นหาจะกรองรายการที่มองเห็นโดยไม่ลบรายการใด

กฎแบบกำหนดเองมี [คู่มือโค้ด](../code-manual/th.md) แยกต่างหาก ซึ่งอธิบายตัวแก้ไข การเปิดใช้ บันทึก การเข้าถึงไฟล์ และ API ที่รองรับ

## แอปพื้นฐาน

ใช้ตัวเลือก + ของเป้าหมาย Apps เพื่อเลือกแอปที่ติดตั้ง **บล็อกทุกแอปยกเว้นรายการเหล่านี้** จะเปลี่ยนรายการเป็นรายการอนุญาต แอประบบ เบราว์เซอร์ และ Vault เองจะไม่ถูกบล็อกในระดับแอปพื้นฐาน

ระบบจะขอให้แอปที่ถูกบล็อกปิด **ขอให้แอปที่ถูกบล็อกปิดอีกครั้งทุก (นาที)** ควบคุมการลองซ้ำ การเปลี่ยนเส้นทางเว็บไซต์ การหยุดหน้าชั่วคราว และการซ่อนฟีดบังคับใช้โดยส่วนขยายเบราว์เซอร์ ไม่ได้กลายเป็นการกระทำกับแอปพื้นฐาน

## ตัวจัดประเภท

กลุ่มตัวจัดประเภทติดแท็กเนื้อหาจากแพลตฟอร์มที่กำหนด โดยใช้โครงสร้างแท็กและการตั้งค่าโมเดลของกลุ่มนั้น แต่ละแพลตฟอร์มอยู่ได้เพียงกลุ่มเดียว เลือกแพลตฟอร์มตอนสร้างกลุ่มและเปลี่ยนภายหลังไม่ได้ ตารางเวลาและตัวกรองของกลุ่มการบล็อกไม่มีผลกับการติดแท็ก

เปิดใช้การติดแท็กในการตั้งค่าตัวจัดประเภท ใช้ **พักการติดแท็ก / ทำการติดแท็กต่อ** แยกกันในแต่ละกลุ่ม การปิดบันทึกฟีดของแพลตฟอร์มใน **Activity → การบันทึก** จะหยุดการติดแท็กของฟีดนั้นด้วย

### แท็กและการตั้งค่าโมเดล

สร้างแท็ก อธิบายความหมาย และตั้งค่าหรือนำแท็กแม่ออกในโครงสร้างแท็ก ลากแท็กเพื่อย้ายสาขา คำอธิบายที่ชัดเจนช่วยให้โมเดลแยกแท็กที่คล้ายกันได้ การตั้งค่าของแต่ละกลุ่มเป็นอิสระจากกัน

- **ความเร็ว ↔ คุณภาพ** เลือกระดับโมเดลในเครื่อง โมเดลขนาดใหญ่ใช้หน่วยความจำมากขึ้น; ความเร็วและผลลัพธ์ขึ้นอยู่กับ Mac และภาระงาน การดาวน์โหลดใช้ร่วมกันระหว่างกลุ่ม
- **เข้มงวด ↔ ครอบคลุม** กำหนดความเชื่อมั่นที่ต้องการและจำนวนแท็กเริ่มต้น
- **แท็กขั้นต่ำ / แท็กสูงสุด** ในเพิ่มเติมจะแทนจำนวนเริ่มต้นเหล่านั้น แต่ เข้มงวด ↔ ครอบคลุม ยังคงควบคุมความเชื่อมั่นสำหรับแท็กเพิ่มเติม เว้นช่องใดว่างเพื่อใช้ค่าเริ่มต้น
- **คำแนะนำการติดแท็ก** เพิ่มคำสั่งเสริมสำหรับกลุ่มนี้

การแก้ไขทั่วไปในตัวจัดประเภทจะบันทึกโดยอัตโนมัติ ต้องดาวน์โหลดระดับที่เลือกก่อนจึงจะติดแท็กได้ กลุ่มที่ใช้ระดับเดียวกันจะแชร์โมเดลที่โหลดอยู่ โดยโหลดค้างไว้ได้พร้อมกันสูงสุดสองระดับ

แก้แท็กของรายการเนื้อหาในส่วนขยายเบราว์เซอร์ คลิก **+ แท็ก** ค้นหาแท็กที่มีอยู่ในตัวจัดประเภท แล้วเลือกเพื่อเพิ่ม ใช้ตัวควบคุมลบของแท็ก หรือเลือกแท็กแล้วกด Delete หนึ่งครั้งเพื่อลบ **ไม่มีแท็ก** หมายถึงการติดแท็กเสร็จแล้วแต่ไม่พบแท็ก ส่วน **กำลังติดแท็ก** หมายถึงผลลัพธ์ยังรออยู่ การแก้ไขจะช่วยปรับปรุงการติดแท็กในอนาคต

## Knowledge และการวิจัยบนเว็บ

Knowledge จัดเก็บคำอธิบายสั้น ๆ ไว้ใน Mac นี้สำหรับโมเดลติดแท็กในเครื่อง **แหล่งเนื้อหา** รวมครีเอเตอร์ บัญชี ช่อง และชุมชน คำอธิบายแหล่งที่มาจะแนบไปกับเนื้อหาของแหล่งนั้น **คำที่รู้จัก** จะมีผลเมื่อคำนั้นปรากฏในชื่อเรื่อง

เพิ่มแหล่งที่มาหรือคำพร้อมคำอธิบาย หรือเว้นคำอธิบายว่างไว้เพื่อขอการวิจัยเมื่อเปิดใช้ คำแนะนำครีเอเตอร์ช่วยค้นหาแหล่งที่ตัวจัดประเภทเก็บไว้แล้ว รายการที่มีอย่างน้อยหกรายการจะมีช่องค้นหาอยู่ด้านบนโดยตรง: Terms และ Content sources ของแต่ละแพลตฟอร์มค้นหาชื่อ ตัวระบุ หรือคำอธิบายแยกกัน การแก้คำอธิบายมีผลกับการติดแท็กครั้งต่อไป; การลบความรู้ของแหล่งไม่ได้ป้องกันไม่ให้การวิจัยสร้างขึ้นมาอีก

### ตั้งค่าผู้ให้บริการวิจัย

1. เปิด **การตั้งค่าตัวจัดประเภท → API keys & providers**
2. เลือกประเภทผู้ให้บริการและ **เพิ่มผู้ให้บริการ** ขั้นตอนนี้สร้างการตั้งค่า ไม่ได้ออก API key
3. ขอข้อมูลรับรองจากผู้ให้บริการนั้นแล้วป้อน หากใช้ endpoint แบบกำหนดเองที่เข้ากันได้ ให้ตั้งค่า endpoint และ protocol เพิ่มด้วย
4. ใน **การวิจัยบนเว็บ** เลือกผู้ให้บริการที่มี web search ในตัว ดึงรายการโมเดลแล้วเลือกโมเดลวิจัย ใช้การค้นหาในตัวเลือกโมเดลเพื่อกรองรายการ; รีเฟรชเพื่อดึงรายการใหม่
5. อ่านการเปิดเผยข้อมูลความยินยอมและเปิดใช้ความยินยอม ในแต่ละกลุ่มเลือก **เปิด**, **ปิด** หรือ **ตามการตั้งค่าตัวจัดประเภท**

**ตั้งค่าการวิจัยบนเว็บ…** จะพาไปยังการตั้งค่าเมื่อยังตั้งค่าไม่ครบ กลุ่มไม่สามารถข้ามความยินยอมการวิจัยได้ **ทดสอบการเชื่อมต่อ** ยืนยันเพียงว่าคำขอทดสอบสำเร็จ ไม่ได้ยืนยันว่าทุกโมเดลรองรับการวิจัย โมเดลทดสอบของผู้ให้บริการแยกจากโมเดลวิจัยที่เลือก

Keys จัดเก็บในโฟลเดอร์ support ของแอปบน Mac นี้ ไม่ได้อยู่ใน system Keychain ใช้ยืนยันคำขอไปยังผู้ให้บริการที่กำหนดค่าไว้; Vault ไม่อัปโหลด keys ไปยังเซิร์ฟเวอร์ของตนเอง การวิจัยส่งหัวข้อสาธารณะที่ผ่านการลบข้อมูลระบุตัวตนไปยังผู้ให้บริการที่เลือก ไม่ส่งเนื้อหาส่วนตัวหรือสรุป ให้อ่านการเปิดเผยข้อมูลความยินยอมเพื่อดู fields ที่ส่งอย่างละเอียด การใช้งานผู้ให้บริการรวมคำขอทดสอบการเชื่อมต่อและรายการโมเดล รวมถึงการวิจัย

สถานะการวิจัยแสดงคำขอที่เข้าคิว ช่วงพักก่อนลองใหม่ ความล้มเหลว และการใช้ tokens ของวันนั้น **ลองหัวข้อที่ล้มเหลวอีกครั้งตอนนี้** จะลองเฉพาะรายการที่เข้าเกณฑ์; ไม่ข้ามขีดจำกัดรายวันหรือความยินยอม

## Activity

Activity บันทึกการใช้แอปที่เปิดไว้ การเยี่ยมชมเว็บไซต์ และ **เนื้อหาที่ดู** ซึ่งรองรับไว้ในเครื่อง แผนภูมิสะท้อนข้อมูลที่บันทึกไว้; พื้นที่ว่างไม่ได้พิสูจน์ว่า Mac ไม่ได้ใช้งาน

เลือกช่วงวันที่ **ไทม์ไลน์** แสดงการใช้งานตามเวลาของวัน; **ยอดรวม** รวมระยะเวลา **ช่วงเวลา** จะรวมการใช้งานภายในแต่ละช่วงเป็นแท่งแนวตั้ง **สี** เป็นคำอธิบายสัญลักษณ์ที่คลิกได้: เลือกแหล่งเพื่อเน้นแผนภูมิไปที่แหล่งนั้น เลือกวันเพื่อดูการใช้งานนับจากวันนั้น

### กลุ่ม Activity

สร้างกลุ่มเพื่อแสดงแอปและเว็บไซต์ที่เลือกไว้ด้วยกันใน Usage **รวม** ใช้ชื่อและสีเดียวกับสมาชิกใน Activity ทั้งหมด กลุ่ม Activity จัดระเบียบการใช้งานที่บันทึกไว้ แยกจากกลุ่มการบล็อกและกลุ่มตัวจัดประเภท บันทึกตัวแก้ไขกลุ่ม Activity อย่างชัดเจนด้วย **บันทึก**

### การบันทึกและระยะเวลาเก็บข้อมูล

ใน **การบันทึก** เปิดหรือปิดการบันทึกแยกตามหมวดหรือแหล่งแต่ละรายการ **เก็บไว้** กำหนดระยะเวลาที่เก็บประวัติ; **ตลอดไป** จะเก็บไว้โดยไม่หมดอายุอัตโนมัติ การเลือกเฉพาะรายการสามารถใช้ค่าตามการตั้งค่าทั่วไปได้ การปิดการบันทึกจะหยุดบันทึกข้อมูลใหม่; การลบประวัติจะนำรายการที่บันทึกไว้แล้วออก

ฟีดแพลตฟอร์มรวบรวมเนื้อหาที่แสดงบนหน้าของแพลตฟอร์มที่รองรับ ไม่ว่าจะเปิดหน้าค้างไว้หรือไม่ ฟีดที่แสดง **รองรับการติดแท็ก** จะส่งข้อมูลให้ตัวจัดประเภทได้เมื่อเปิดการบันทึก การเก็บรักษาของฟีดควบคุมเนื้อหาที่รวบรวมแยกจากการใช้งานแอปและเว็บไซต์ การพักกลุ่มตัวจัดประเภทไม่ได้ปิดการบันทึกด้วยตัวเอง

## การตั้งค่าตัวจัดประเภท

**การอัปเดตแพ็กเกจแท็ก** กำหนดเวลาที่แพ็กเกจแท็กที่ตรวจสอบแล้วมีผล: **อัตโนมัติ**, **ถามก่อน** หรือ **ด้วยตนเอง** การตั้งค่านี้แยกจากการดาวน์โหลดโมเดลในเครื่องที่เลือกไว้ในกลุ่ม เมื่อเลือก **ดาวน์โหลด** ไฟล์โมเดลจะดาวน์โหลดจาก Hugging Face ระหว่างดาวน์โหลดให้ใช้สถานะ/ความคืบหน้าของกลุ่มและตัวควบคุม **ยกเลิก**

เลือกภาษาส่วนติดต่อใน Settings คำอธิบายช่องต่าง ๆ มีให้ผ่านปุ่ม Info ขนาดเล็กในภาษาส่วนติดต่อที่เลือก

## การบันทึกและการแก้ปัญหา

การแก้ไขทั่วไปใน Vault และตัวจัดประเภทจะบันทึกโดยอัตโนมัติ การแก้ไขกลุ่ม Activity ต้องกด **บันทึก** การเพิ่ม การลบ การดาวน์โหลดโมเดล การทดสอบการเชื่อมต่อ และการดึงรายการโมเดลเป็นการกระทำที่ต้องสั่งเอง

หากไม่มีแท็ก ให้ตรวจการเชื่อมต่อเบราว์เซอร์ สวิตช์เปิดใช้การติดแท็กโดยรวม สถานะพักกลุ่ม การบันทึกของแพลตฟอร์ม และการดาวน์โหลดโมเดล หากการวิจัยไม่ทำงาน ให้ตรวจความยินยอม การเลือกกลุ่ม ข้อมูลรับรองผู้ให้บริการ โมเดลวิจัย และสถานะการวิจัย หากแก้กลุ่มที่เชื่อมโยงไม่ได้ ให้เชื่อมต่อโปรแกรมอีกครั้งหรือเลิกตรึงตามคำแนะนำ
