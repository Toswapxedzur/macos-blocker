# คู่มือผู้ใช้ Mac Vault

Mac Vault มีสามหน้า: **Vault** บล็อกแอปเนทีฟ, **การติดแท็กเนื้อหา** ติดแท็กเนื้อหาเบราว์เซอร์ที่รองรับ และ **กิจกรรม** แสดงการใช้งานที่บันทึกไว้ ส่วนขยายเบราว์เซอร์รวบรวมเนื้อหาที่รองรับและใช้การบล็อกในเบราว์เซอร์ ติดตั้งและเชื่อมต่อในเบราว์เซอร์ที่ใช้

## เริ่มต้นอย่างรวดเร็ว

1. ใน **Vault** เพิ่ม บล็อกกลุ่ม และเป้าหมาย Apps จากนั้นเลือกแอปด้วยตัวเลือก +
2. เลือกพฤติกรรมการบล็อกและเปิดใช้กลุ่ม
3. ใน **การติดแท็กเนื้อหา** สร้างกลุ่ม เลือกแพลตฟอร์ม และเพิ่มแท็กพร้อมคำอธิบาย
4. ไปที่ การตั้งค่า → **การเชื่อมต่อ AI** แล้วเลือก ChatGPT subscription, OpenAI API, Gemini API หรือ Grok API เชื่อมต่อบัญชีหรือป้อน key และดึงรายการโมเดล จากนั้นเลือก connection/model ในกลุ่ม เปิดใช้ tagging และกลับมาทำงานต่อ
5. เปิดเนื้อหาที่รองรับในเบราว์เซอร์ที่เชื่อมต่อ ตั้งตัวกรองแท็กใน browser บล็อกกลุ่ม หากต้องการให้แท็กควบคุมการบล็อก

## กลุ่มการบล็อก

**บล็อกกลุ่ม** ใช้นโยบายการบล็อก ส่วน **การติดแท็กเนื้อหา** กำหนดแท็กให้เนื้อหาแต่ไม่ได้บล็อกด้วยตัวเอง เพิ่มและตั้งชื่อกลุ่ม เลือกเป้าหมายใน **ใช้กับ** กำหนดเวลาที่บล็อกและตั้งตารางหรือโควตาเวลา แล้วเปิดใช้กลุ่ม การแก้ไขทั่วไปจะบันทึกอัตโนมัติ ข้อผิดพลาดหมายถึงการแก้ไขไม่ได้รับการยอมรับ ให้แก้ฟิลด์และลองใหม่ การปิดกลุ่มหยุดนโยบายแต่เก็บการตั้งค่าไว้; **ลบกลุ่ม** จะลบกลุ่ม ลากกลุ่มเพื่อจัดลำดับ หลายกลุ่มอาจใช้กับเป้าหมายเดียวกัน การ snooze กลุ่มหนึ่งไม่ยกเลิกการบล็อกของอีกกลุ่ม **ส่งออก** คัดลอกการตั้งค่า; **นำเข้า** แทนที่กลุ่มที่เลือกหลังยืนยัน

### โควตาเวลาและตาราง

**Block immediately** บล็อกเมื่อกลุ่มที่เปิดใช้ตรงเงื่อนไขและตารางทำงาน **Block when the time allowance is used** อนุญาตให้ใช้จนโควตาหมด ตั้งโควตาเป็นนาทีและช่วงรีเซ็ตเป็นชั่วโมง Rolling limit นับการใช้ในหน้าต่างเวลาก่อนหน้า การรีเซ็ตเที่ยงคืนเริ่มช่วงใหม่ตามเวลาเที่ยงคืนท้องถิ่น แม้เป็น rolling limit เลือกวันทำงานและช่วงเวลาท้องถิ่นที่เลือกได้ บรรทัดละหนึ่งช่วง เช่น **09:00-12:00** ถ้าไม่ระบุช่วงจะใช้ตลอดวันที่เลือก ช่วงเวลาต้องสิ้นสุดหลังเวลาเริ่มในวันเดียวกัน แบ่งตารางข้ามคืนเป็นคนละวัน

### พักชั่วคราว

ตั้ง snooze แยกในแต่ละ บล็อกกลุ่ม **Pause blocking** ระงับนโยบายตามระยะเวลาพัก **Add to the time allowance** เพิ่มนาทีที่ใช้ได้ให้กลุ่มที่มีโควตา นับเป็นเวลา snooze เฉพาะส่วนเพิ่มที่ใช้จริง ส่วนที่ไม่ได้ใช้หมดอายุเมื่อรีเซ็ตครั้งถัดไป; สำหรับ rolling limit จะหมดหลังหนึ่งหน้าต่าง หรือเร็วกว่านั้นที่เที่ยงคืนหากเปิดการรีเซ็ตไว้ **Activation delay** เลื่อน snooze โดยยังคงบล็อก **Cooldown** คือเวลารอก่อนส่งคำขอครั้งต่อไปหลัง snooze จบ **Required confirmations** กำหนดจำนวนขั้นยืนยัน กลุ่มที่ freeze ใช้ snooze ได้เฉพาะเมื่ออนุญาตไว้ก่อน freeze

### Freeze และ PIN

**Freeze** ป้องกันการแก้ไขทั่วไป การยกเลิก freeze ต้องยืนยันสิบครั้ง ห่างกันครั้งละห้าวินาที พร้อมรอเวลาที่กำหนดและใช้ PIN หกหลัก **Wait before unfreezing** รับค่า 0–72 ชั่วโมง; 0 คือไม่ต้องรอ ขณะ freeze เพิ่มเวลารอและเพิ่ม PIN หากยังไม่มีได้ แต่ลดเงื่อนไขไม่ได้จนกว่าจะยกเลิก freeze การลบก็ต้องรอเวลาที่เหลือและใส่ PIN ตามเงื่อนไข

### กลุ่มที่เชื่อมโยง

ใช้ **เชื่อมโยง** เชื่อมกลุ่มที่เลือกอย่างชัดเจนจากโปรแกรม Vault อื่น กลุ่มที่เชื่อมโยงแบ่งปันชื่อ การตั้งค่านโยบายที่รองรับ เป้าหมาย การใช้งาน และเงื่อนไข freeze แต่ละโปรแกรมแก้ไขและบังคับใช้ชนิดเป้าหมายที่รองรับ; เป้าหมายชนิดอื่นยังใช้ได้ในโปรแกรมที่เชื่อมโยง **ยกเลิกการเชื่อมโยง** ตัดการเชื่อมต่อแต่คงกลุ่มและการตั้งค่าไว้ หากสมาชิกออฟไลน์ ให้เปิด Mac Vault และเบราว์เซอร์ที่เชื่อมไว้เพื่อเชื่อมต่อใหม่ นโยบายที่บันทึกในเครื่องอาจยังมีผลขณะออฟไลน์

## ขอความช่วยเหลือ

คลิก **i** เล็กข้างฟิลด์เพื่อดูคำอธิบาย คลิกด้านนอกหรือกด Escape เพื่อปิด รายการอยู่ในกล่องเลื่อนได้; การค้นหากรองรายการที่เห็นโดยไม่ลบรายการ คู่มือ [Code manual](../code-manual/th.md) สำหรับ custom rules อธิบาย editor, activation, logs, file access และ API

## แอปเนทีฟ

ใช้ตัวเลือก + ของเป้าหมาย Apps เพื่อเลือกแอปที่ติดตั้งหรือกำลังทำงาน เปิดตัวเลือกอีกครั้งเพื่อรีเฟรชหลังเริ่มแอปจากโฟลเดอร์อื่น **บล็อกทุกแอปยกเว้นแอปที่ระบุไว้ที่นี่** เปลี่ยนรายการเป็น allowlist Mac Vault บล็อกแอป Apple ทั่วไปและเบราว์เซอร์ทั้งตัวได้ แต่ Mac Vault เองและแอปที่ใช้ bundle identifier เดียวกันยังได้รับการปกป้อง แอปที่ถูกบล็อกจะได้รับคำขอให้ออกจากแอป **ขอให้แอปที่ถูกบล็อกปิดอีกครั้งทุก (นาที)** กำหนดช่วงเวลาลองซ้ำ การเปลี่ยนเส้นทางเว็บไซต์ การพักหน้า และการซ่อน feed เป็นหน้าที่ของส่วนขยายเบราว์เซอร์ ไม่ใช่การทำงานของแอปเนทีฟ

## การติดแท็กเนื้อหา

แต่ละกลุ่มติดแท็กเนื้อหาจากแพลตฟอร์มที่กำหนดด้วย tag tree และการตั้งค่าโมเดลของตนเอง แต่ละแพลตฟอร์มอยู่ได้กลุ่มเดียว เลือกตอนสร้างและเปลี่ยนภายหลังไม่ได้ ตารางและตัวกรองการบล็อกไม่ควบคุม tagging เปิด tagging ใน การตั้งค่า และใช้ **พักการติดแท็ก / เริ่มติดแท็กอีกครั้ง** แยกตามกลุ่ม การปิดการบันทึก feed ของแพลตฟอร์มใน **กิจกรรม → กำลังบันทึก** จะหยุด tagging ของ feed นั้นด้วย

### แท็กและการตั้งค่าโมเดล

สร้างแท็ก อธิบายความหมาย และกำหนดหรือลบ parent ใน tree ลากแท็กเพื่อย้าย branch คำอธิบายที่ชัดช่วยให้โมเดลแยกแท็กคล้ายกันได้ การตั้งค่าแต่ละกลุ่มเป็นอิสระ **ความเชื่อมั่นขั้นต่ำของแท็ก** กำหนดระดับหลักฐานของแท็กที่ทำนาย ตั้งแต่ 1–5 กลุ่มใหม่เริ่มที่ 4 (หลักฐานแน่น) ไม่มีจำนวนแท็กเป้าหมาย รายการอาจไม่มีแท็ก **คำแนะนำการติดแท็ก** บันทึกความต้องการของกลุ่ม การแก้ไขทั่วไปบันทึกอัตโนมัติ แต่ละกลุ่มใช้ connection, model และ reasoning effort ที่เลือกไว้อย่างชัดเจน

### การเชื่อมต่อ AI

การตั้งค่า มี ChatGPT subscription, OpenAI API, Gemini API และ Grok API การสมัครใช้การลงชื่อเข้าใช้ของ Vault และแผนที่เข้าเกณฑ์ API key ใช้การเรียกเก็บเงินและขีดจำกัดของผู้ให้บริการที่เลือก เลือกผู้ให้บริการแล้วป้อน key ใต้ dropdown ส่วนกลาง การแก้ไข key บันทึกอัตโนมัติ; ล้างฟิลด์เพื่อลบ key เลือก **ดึงรายการโมเดล** แล้วเลือกรุ่นในกลุ่ม การติดแท็กเนื้อหา หรือ custom-rule การดึงรายการไม่ได้เลือกรุ่นให้

**ระดับการให้เหตุผล** กำหนดระดับการคิดของโมเดล: Model default, Low, Medium หรือ High หากรองรับ การเลือกใหม่เริ่มที่ Medium ส่วนค่าที่มีอยู่ยังคงเดิม ระดับสูงอาจเพิ่มเวลาและ token การค้นหาเว็บเปิดใช้งานเสมอสำหรับ tagging; โมเดลตัดสินใจว่าจะค้นเมื่อใด เลือกโมเดลที่รองรับการค้นหาและ structured tagging คำขอที่ล้มเหลวหรือใช้ไม่ได้ยังเก็บผล cache ที่ถูกต้อง รายการใหม่ยังไม่คลี่คลายจนเลือก **ลองจัดประเภทบนคลาวด์อีกครั้ง** Vault ไม่สลับผู้ให้บริการอัตโนมัติ แต่ละ connection มีช่วง retry และจำนวนครั้งของตนเอง แก้แท็กในส่วนขยาย: คลิก **+ tag** ค้นหาแล้วเลือกเพื่อเพิ่ม ใช้ปุ่มลบหรือเลือกแท็กแล้วกด Delete หนึ่งครั้งเพื่อลบ **ไม่มีแท็ก** หมายถึง tagging เสร็จโดยไม่มีแท็ก; **กำลังติดแท็ก** หมายถึงผลลัพธ์กำลังรอ การแก้ของคุณมีผลเหนือรายการนั้น

## กิจกรรม

กิจกรรม บันทึกการใช้แอปที่เปิดใช้ การเข้าชมเว็บไซต์ และ **เนื้อหาที่ดูแล้ว** ที่รองรับไว้ในเครื่อง กราฟแสดงข้อมูลที่บันทึก ช่องว่างไม่ได้พิสูจน์ว่า Mac ไม่ได้ใช้งาน เลือกช่วงวันที่ **ไทม์ไลน์** แสดงการใช้ตามเวลาของวัน; **รวม** รวมระยะเวลา; **ช่วงเวลา** รวมการใช้แต่ละช่วงเป็นบล็อกแนวตั้ง **สี** เป็น legend ที่คลิกได้ เลือกแหล่งข้อมูลเพื่อโฟกัสกราฟ เลือกวันเพื่อดูการใช้ตั้งแต่วันนั้น

### กลุ่ม กิจกรรม

สร้างกลุ่มเพื่อแสดงแอปและเว็บไซต์ที่เลือกไว้ร่วมกันใน Usage **Merge** ใช้ชื่อและสีเดียวสำหรับสมาชิกทั่วทั้ง กิจกรรม กลุ่ม กิจกรรม จัดระเบียบการใช้ที่บันทึกไว้ แยกจาก บล็อกกลุ่ม และ การติดแท็กเนื้อหา กด **Save** ใน editor อย่างชัดเจน

### การบันทึกและการเก็บรักษา

ใน **กำลังบันทึก** เปิดหรือปิดการบันทึกในแต่ละหมวดหรือแหล่งข้อมูล **เก็บไว้** กำหนดระยะเวลาการเก็บประวัติ; **ตลอดไป** ไม่หมดอายุอัตโนมัติ ตัวเลือกแต่ละรายการอาจตามค่ารวม การปิด recording หยุดการบันทึกใหม่; การลบ history ลบรายการที่บันทึกไว้ Platform feed รวบรวมเนื้อหาที่แสดงบนหน้าที่รองรับ ไม่ว่าจะเปิดหน้าหรือไม่ Feed **รองรับการติดแท็ก** ป้อนเนื้อหาให้ การติดแท็กเนื้อหา ได้เมื่อ recording เปิดอยู่ ระยะเก็บของ feed แยกจากการใช้แอปและเว็บไซต์ การพักกลุ่ม tagging ไม่ได้หยุด recording เอง

## การตั้งค่า

เลือกภาษาส่วนติดต่อใน การตั้งค่า คำอธิบายฟิลด์แสดงผ่านปุ่ม Info ในภาษาที่เลือก

## การบันทึกและแก้ปัญหา

การแก้ไข Vault และ การติดแท็กเนื้อหา ทั่วไปบันทึกอัตโนมัติ; editor ของ กิจกรรม group ต้องกด **Save** การเพิ่ม ลบ ทดสอบการเชื่อมต่อ และดึงโมเดลเป็นการกระทำที่ต้องสั่ง หากไม่มีแท็ก ให้ตรวจการเชื่อมต่อเบราว์เซอร์ สวิตช์ tagging ส่วนกลาง สถานะพักกลุ่ม การบันทึกแพลตฟอร์ม connection/model ที่เลือก และข้อมูลรับรอง หากคำขอ AI ล้มเหลว ให้ตรวจขีดจำกัดผู้ให้บริการและ Log ของกลุ่ม หากแก้กลุ่มเชื่อมโยงไม่ได้ ให้เชื่อมโปรแกรมใหม่หรือยกเลิก freeze ตามข้อความที่แสดง
