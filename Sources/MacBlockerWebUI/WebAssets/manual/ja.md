# Mac Vault ユーザーマニュアル

Mac Vault には3つのページがあります。**Vault** はネイティブアプリをブロックし、**Content tagging** は対応するブラウザーコンテンツにタグを付け、**Activity** は記録した使用状況を表示します。ブラウザー拡張機能は対応コンテンツを収集し、ブラウザーのブロックを適用します。使用するブラウザーにインストールして接続してください。

## クイックスタート

1. **Vault** で blocking group と Apps ターゲットを追加し、+ ピッカーからアプリを選びます。
2. ブロック動作を選び、グループを有効にします。
3. **Content tagging** でグループを作成し、プラットフォームと説明付きタグを設定します。
4. Settings → **AI connections** で ChatGPT subscription、OpenAI API、Gemini API、Grok API のいずれかを選びます。アカウント接続またはキー入力を行ってモデルを取得し、グループで接続/モデルを選択します。タグ付けを有効にしてグループを再開します。
5. 接続したブラウザーで対応コンテンツを開きます。タグでブロックを制御する場合は、ブラウザーの blocking group にタグフィルターを設定します。

## ブロックグループ

**Blocking group** はブロックポリシーを適用します。**Content tagging group** はコンテンツにタグを付けますが、それだけではブロックしません。グループを追加して名前を付け、**Applies to** で対象を選び、適用時刻とスケジュールまたは時間枠を設定して有効にします。通常の編集は自動保存されます。エラーは変更が受け付けられなかったことを示します。無効化すると設定を保ったままポリシーを停止します。**Delete group** は削除します。ドラッグして順序を変更します。同じ対象に複数グループが適用される場合があり、一方の snooze は別グループのブロックを解除しません。**Export** は設定をコピーし、**Import** は確認後に選択グループの設定を置き換えます。

### 時間枠とスケジュール

**Block immediately** は有効なグループとスケジュールが一致するとブロックします。**Block when the time allowance is used** は枠を使い切るまで利用を許可します。枠は分、リセット間隔は時間で指定します。ローリング制限は直前のウィンドウ内の利用を数えます。深夜リセットはローリング制限でも現地の深夜に新しい期間を始めます。有効な曜日と任意の現地時間帯を1行ずつ指定します（例 **09:00-12:00**）。時間帯が空なら選択した曜日全体に適用されます。同日の終了時刻は開始時刻より後にします。夜間の予定は日ごとに分けてください。

### Snooze

各 blocking group で snooze を設定します。**Pause blocking** は設定時間だけポリシーを一時停止します。**Add to the time allowance** は時間制限グループに使える分数を加えます。消費した追加枠だけが snoozed time になります。未使用分は次のリセット時に失効します。ローリング制限では1ウィンドウ後、深夜リセットが有効ならそれより早く失効する場合があります。**Activation delay** はブロックを続けながら snooze を遅らせます。**Cooldown** は終了後の次の要求までの待ち時間です。**Required confirmations** は確認段階数です。凍結前に許可した場合に限り、凍結グループでも snooze を使用できます。

### Freeze と PIN

**Freeze** は通常の編集を防ぎます。解除には5秒間隔の確認10回、設定された待ち時間、6桁の PIN が必要です。**Wait before unfreezing** は0～72時間で、0は待ち時間なしです。凍結中に待ち時間を延長したり、PIN がなければ追加したりできますが、解除するまで条件を緩和できません。削除にも残りの待ち時間と PIN が適用されます。

### リンク済みグループ

**Link** で他の Vault プログラムから明示的に選んだグループを接続します。名前、対応するポリシー設定、対象、使用状況、凍結条件を共有します。各プログラムは対応する対象タイプを編集・適用し、ほかの対象もリンク先で利用できます。**Unlink** はグループと設定を保持したまま切断します。メンバーがオフラインの場合、Mac Vault とリンク先ブラウザーを開いて再接続します。ローカル保存済みポリシーはオフライン中も適用される場合があります。

## ヘルプ

項目横の **i** をクリックすると説明が表示されます。外側をクリックするか Escape で閉じます。リストはスクロール領域内にあり、検索は項目を削除せず表示を絞り込みます。カスタムルールについては[コードマニュアル](../code-manual/ja.md)を参照してください。エディター、起動、ログ、ファイルアクセス、API を説明します。

## ネイティブアプリ

Apps ターゲットの + ピッカーでインストール済みまたは実行中のアプリを選びます。別フォルダーからアプリを起動したら、ピッカーを開き直して一覧を更新します。**Block every app except these** は一覧を許可リストにします。Mac Vault は通常の Apple アプリやブラウザー全体をブロックできますが、Mac Vault 自身と同じ bundle identifier を共有するアプリは保護されます。ブロック対象アプリには終了を要求します。**Ask a blocked app to quit again every (minutes)** は再要求間隔です。Web リダイレクト、ページ一時停止、フィード非表示はブラウザー拡張機能が適用し、ネイティブアプリの動作にはなりません。

## Content tagging

各グループは割り当てられたプラットフォームのコンテンツに、独自のタグツリーとモデル設定でタグを付けます。各プラットフォームは1つのグループに属します。作成時に選び、後から変更できません。ブロックグループの予定やフィルターはタグ付けを制御しません。Settings で有効にし、各グループの **Pause tagging / Resume tagging** を個別に使います。**Activity → Recording** でプラットフォームフィードの記録を止めると、そのタグ付けも止まります。

### タグとモデル設定

タグを作成して意味を説明し、ツリーで親を設定/解除します。ドラッグすると枝を移動します。明確な説明は似たタグの識別に役立ちます。グループごとに設定は独立しています。**Minimum confidence** は予測タグに必要な根拠レベルを1～5で設定します。新規グループは4（強い根拠）です。タグ数の目標はなく、タグなしになる場合もあります。**Tagging instructions** はグループの希望を記録します。通常の編集は自動保存され、各グループは明示的に選んだ接続、モデル、推論強度を使います。

### AI connections

Settings の選択肢は ChatGPT subscription、OpenAI API、Gemini API、Grok API です。ChatGPT subscription は Vault のサインインと対象プランを使います。API キーは選択したプロバイダーの課金と利用上限に従います。プロバイダーを選び、共通ドロップダウンの直下にキーを入力します。キー変更は自動保存され、欄を空にすると削除されます。**Fetch model list** でモデルを取得し、Content tagging または custom-rule グループで選びます。取得しただけでは選択されません。

**Reasoning effort** はモデルの思考量です。対応モデルでは Model default、Low、Medium、High を選べます。新規選択は Medium から始まり、既存の選択は保持されます。高い強度は時間とトークンを増やす場合があります。タグ付けでは Web 検索が常に有効で、使用時期はモデルが決めます。検索と構造化タグ付けに対応するモデルを選んでください。失敗/利用不能時も有効なキャッシュ結果は保持され、新しい項目は **Retry cloud classification** を選ぶまで未解決です。Vault は自動でプロバイダーを切り替えません。接続ごとに再試行間隔と上限があります。拡張機能で **+ tag** を押し、検索して追加します。削除操作またはタグを選択して Delete を1回押すと削除できます。**Untagged** はタグなしで完了、**Tagging** は結果待ちを示します。修正内容はその項目で優先されます。

## Activity

Activity は有効なアプリ使用、Web サイト訪問、対応する **Content viewed** をローカル記録します。グラフは記録データを示し、空白でも Mac のアイドル状態を証明しません。期間を選びます。**Timeline** は時刻別、**Totals** は時間合計、**Time interval** は各間隔の利用を縦ブロックにまとめます。**Colors** はクリックできる凡例で、ソースを選ぶとグラフを絞れます。日付を選ぶとその日以降の使用を表示します。

### Activity groups

選択したアプリと Web サイトを Usage にまとめて表示するグループを作成します。**Merge** は Activity 全体でメンバーの名前と色を統一します。Activity group は記録使用を整理するもので、ブロックグループ/タグ付けグループとは別です。エディターで **Save** を明示的に押します。

### Recording と retention

**Recording** でカテゴリまたは個別ソースの記録を切り替えます。**Keep** は履歴の保存期間、**Forever** は自動期限なしです。個別設定は上位設定に従う場合があります。記録を止めると新しい記録が停止し、履歴を削除すると記録済み項目が消えます。プラットフォームフィードは、開いたかどうかにかかわらず対応ページに表示されたコンテンツを収集します。**Tagging supported** フィードは記録中に Content tagging へ提供できます。保持設定はアプリ/サイト使用とは別です。タグ付けグループを一時停止しても記録自体は停止しません。

## Settings

Settings でインターフェース言語を選択します。項目の説明は選択言語の Info ボタンにあります。

## 保存とトラブルシューティング

通常の Vault と Content tagging の編集は自動保存です。Activity group の編集には **Save** が必要です。追加、削除、接続テスト、モデル取得は明示的な操作です。タグがない場合はブラウザー接続、全体タグ付けスイッチ、グループ一時停止、プラットフォーム記録、接続/モデル、認証情報を確認します。AI 失敗時はプロバイダーの利用上限とグループ Log も確認してください。リンク済みグループを編集できない場合はプログラムを再接続するか、表示に従って凍結解除します。
