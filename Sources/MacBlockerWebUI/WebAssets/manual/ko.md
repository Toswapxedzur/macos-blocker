# Mac Vault 사용자 설명서

Mac Vault에는 세 페이지가 있습니다. **Vault**는 native app을 차단하고, **분류기**는 지원되는 브라우저 콘텐츠에 태그를 달며, **활동**은 기록된 사용을 보여 줍니다. 브라우저 확장 프로그램은 지원 콘텐츠를 수집하고 브라우저 차단을 적용합니다. 사용하는 브라우저에 설치하고 연결하세요.

## 빠른 시작

1. **Vault**에서 차단 그룹과 Apps 대상을 추가한 뒤 + 선택기로 앱을 고릅니다.
2. 그룹의 차단 방식을 고르고 활성화합니다.
3. **분류기**에서 그룹을 만들고 플랫폼을 선택한 뒤 설명과 태그를 추가합니다.
4. 로컬 모델 등급을 선택하고 필요하면 내려받습니다. 분류기 설정에서 태그 지정을 켜고 그룹을 다시 시작합니다.
5. 연결된 브라우저에서 지원 콘텐츠를 엽니다. 태그로 차단을 제어하려면 브라우저 차단 그룹에 태그 필터를 설정합니다.

## 차단 그룹

**차단 그룹**은 차단 정책을 적용합니다. **분류기 그룹**은 콘텐츠에 태그를 지정하며, 그 자체로는 차단하지 않습니다.

1. 차단 그룹을 추가하고 이름을 지정하세요.
2. **적용 대상**에서 대상을 선택하세요.
3. 차단을 적용할 시점을 선택하고 일정이나 시간 할당량을 설정하세요.
4. 그룹을 활성화하세요. 대상에는 그룹 정책이 적용됩니다.

일반적인 편집은 자동으로 저장됩니다. 오류가 나면 편집이 승인되지 않은 것이므로 필드를 수정하고 다시 시도하세요. 설정은 유지하면서 정책을 멈추려면 그룹을 비활성화하세요. **그룹 삭제**는 그룹을 제거합니다. 그룹을 끌어 순서를 바꾸세요. 한 대상에 여러 그룹이 적용될 수 있으며, 하나를 잠시 미뤄도 다른 그룹의 차단은 해제되지 않습니다.

**내보내기**는 그룹 구성을 복사합니다. **가져오기**는 확인 후 선택한 그룹의 구성을 바꿉니다.

### 시간 할당량 및 일정

**즉시 차단**은 활성 그룹이 대상과 일치하고 일정이 활성일 때 적용됩니다. **시간 할당량을 다 쓰면 차단**은 할당량이 소진될 때까지 일치하는 사용을 허용합니다.

할당량은 분 단위, 재설정 간격은 시간 단위로 설정하세요. 롤링 한도는 직전 창의 사용량을 셉니다. 자정 재설정은 롤링 한도도 포함해 현지 시각 자정에 새 기간을 시작합니다.

활성 요일과 선택적 현지 시간 창을 한 줄에 하나씩 선택하세요(예: **09:00-12:00**). 창 목록이 비어 있으면 선택한 요일 전체에 적용됩니다. 창은 같은 날 시작 시각보다 늦게 끝나야 합니다. 밤을 넘기는 일정은 날짜별로 나누세요.

### 잠시 미루기

각 차단 그룹에서 미루기를 설정하세요. **차단 일시 중지**는 해당 그룹의 정책을 지정한 시간 동안 중단합니다. **시간 할당량에 추가**는 시간 제한 그룹에 사용할 수 있는 분을 더합니다. 실제로 사용한 추가 할당량만 미룬 시간에 포함됩니다. 사용하지 않은 추가 할당량은 다음 재설정 때 만료됩니다. 롤링 한도에서는 한 창 뒤에, 설정에 따라 자정에 더 일찍 만료됩니다.

**활성화 지연** 중에는 차단이 계속되고 미루기가 늦게 시작됩니다. **대기시간**은 미루기가 끝난 뒤 다음 요청 전까지 기다리는 시간입니다. **필요한 확인 횟수**는 확인 단계 수를 지정합니다. 그룹 동결 전에 허용한 경우에만 동결된 그룹에서 미루기를 사용할 수 있습니다.

### 편집 잠금과 PIN

**동결**은 일반 편집을 막습니다. 해제하려면 5초 간격으로 10회 확인하고, 설정된 대기 시간 및 6자리 PIN이 있다면 입력해야 합니다. **해제 전 대기**는 0~72시간입니다. 0은 추가 대기가 없다는 뜻입니다.

동결된 동안 대기 시간을 늘리고 PIN이 없다면 추가할 수 있습니다. 그룹을 해제할 때까지 이 조건을 완화할 수 없습니다. 삭제에도 남은 대기 시간과 PIN이 적용됩니다.

### 연결된 그룹

**연결**을 사용하면 다른 Vault 프로그램에서 명시적으로 선택한 그룹을 이어 줍니다. 연결된 그룹은 이름, 지원되는 정책 설정, 대상, 사용량, 동결 조건을 공유합니다. 각 프로그램은 지원하는 대상 유형을 편집하고 적용하며, 다른 대상 항목은 연결된 프로그램에서 사용할 수 있습니다. 연결을 해제해도 그룹과 설정은 유지됩니다.

연결된 구성원이 오프라인이면 편집할 수 없을 수 있습니다. 다시 연결하려면 Mac Vault과 연결 브라우저를 여세요. 구성원이 오프라인이어도 로컬 저장 정책은 계속 적용될 수 있습니다.

## 도움말 보기

필드 옆의 작은 **i**를 클릭하면 설명을 볼 수 있습니다. 바깥을 클릭하거나 Escape를 눌러 닫으세요. 목록은 스크롤 가능한 상자 안에 있습니다. 더 보려면 상자 안을 스크롤하세요. 검색은 항목을 삭제하지 않고 보이는 목록만 필터링합니다.

사용자 지정 규칙에는 별도의 [코드 설명서](../code-manual/ko.md)가 있습니다. 편집기, 활성화, 로그, 파일 접근, 지원되는 API를 설명합니다.

## Native 앱

Apps 대상의 + 선택기로 설치된 앱을 고르세요. **이 앱 외에는 모두 차단**하면 목록이 허용 목록이 됩니다. 시스템 앱, 브라우저, Vault 자체는 native app 차단에서 제외됩니다.

차단된 앱에는 종료를 요청합니다. **차단된 앱에 (분)마다 다시 종료 요청**은 재시도를 제어합니다. 웹사이트 리디렉션, 페이지 일시 중지, 피드 숨기기는 브라우저 확장 프로그램이 수행하며 native app 작업이 아닙니다.

## 분류기

분류기 그룹은 할당된 플랫폼의 콘텐츠에 자체 태그 트리와 모델 설정으로 태그를 붙입니다. 각 플랫폼은 한 그룹에만 속합니다. 그룹을 만들 때 플랫폼을 선택하고 이후에는 바꿀 수 없습니다. 차단 그룹의 일정/필터는 태그 지정을 제어하지 않습니다.

분류기 설정에서 태그 지정을 켜세요. 각 그룹에서 **태그 지정 일시 중지 / 다시 시작**을 별도로 사용합니다. **활동 → 기록**에서 플랫폼 피드 기록을 끄면 태그 지정도 중지됩니다.

### 태그와 모델 설정

태그를 만들고 의미를 설명한 뒤 태그 트리에서 부모를 설정하거나 제거합니다. 태그를 끌어 가지를 옮깁니다. 명확한 설명은 모델이 비슷한 태그를 구별하는 데 도움이 됩니다. 그룹별 설정은 독립적입니다.

- **속도 ↔ 품질**은 로컬 모델 등급을 선택합니다. 큰 모델은 메모리를 더 쓰며 속도와 결과는 Mac와 작업량에 따라 달라집니다. 다운로드는 그룹 간 공유됩니다.
- **엄격 ↔ 폭넓음**은 신뢰도 요구사항과 기본 태그 수를 설정합니다.
- 더보기의 **최소 태그 / 최대 태그**는 기본 수를 바꿉니다. 추가 태그의 신뢰도는 계속 엄격 ↔ 폭넓음이 제어합니다. 기본값을 쓰려면 필드를 비워 두세요.
- **태그 지정 지침**은 그룹에 선택적 지침을 추가합니다.

일반적인 분류기 편집은 자동 저장됩니다. 콘텐츠에 태그를 붙이려면 선택한 등급을 내려받아야 합니다. 같은 등급을 쓰는 그룹은 로드된 모델을 공유하며 한 번에 최대 두 등급까지 로드됩니다.

브라우저 확장 프로그램에서 콘텐츠 항목의 태그를 수정하세요. **+ 태그**를 클릭하고 분류기의 기존 태그를 검색해 추가할 태그를 선택합니다. 제거 제어를 누르거나 태그를 선택하고 Delete를 한 번 눌러 삭제하세요. **태그 없음**은 태그 지정 완료 후 태그가 없는 상태, **태그 지정 중**은 결과 대기 상태입니다. 수정은 이후 태그 지정에 반영됩니다.

## 지식과 웹 조사

지식은 로컬 태그 지정 모델을 위해 Mac에 짧은 설명을 저장합니다. **콘텐츠 출처**에는 크리에이터, 계정, 채널, 커뮤니티가 있습니다. 출처 설명은 콘텐츠와 함께 쓰입니다. 제목에 용어가 나타나면 **알려진 용어**가 적용됩니다.

출처나 용어와 설명을 추가하거나, 조사가 켜져 있으면 설명을 비워 조사 요청을 할 수 있습니다. 크리에이터 제안은 분류기가 수집한 출처를 찾는 데 도움을 줍니다. 항목이 6개 이상인 목록은 바로 위에 검색이 있습니다. 용어와 각 플랫폼 콘텐츠 출처는 이름, 식별자, 설명을 각각 검색합니다. 설명을 수정하면 이후 태그 지정에 반영됩니다. 출처 지식을 삭제해도 나중에 조사로 다시 만들어질 수 있습니다.

### 조사 제공자 설정

1. **분류기 설정 → API 키 및 제공자**를 엽니다.
2. 제공자 유형과 **제공자 추가**를 선택합니다. 이는 구성을 만들 뿐 API 키를 발급하지 않습니다.
3. 제공자에게서 자격 증명을 받아 입력합니다. 호환 사용자 지정 endpoint라면 endpoint와 protocol 필드도 설정합니다.
4. **웹 조사**에서 웹 검색이 내장된 제공자를 선택합니다. 모델 목록을 가져와 조사 모델을 고릅니다. 모델 선택기의 검색으로 목록을 좁히고 새로 고침으로 다시 가져올 수 있습니다.
5. 동의 안내를 읽고 동의를 켭니다. 각 그룹에서 **켜기**, **끄기**, **분류기 설정 따르기** 중 선택합니다.

설정이 없으면 **웹 조사 설정…**으로 설정 화면을 엽니다. 그룹은 조사 동의를 우회할 수 없습니다. **연결 테스트**는 테스트 요청 성공을 확인할 뿐 모든 모델의 조사 지원을 보장하지 않습니다. 제공자의 테스트 모델은 선택한 조사 모델과 별개입니다.

키는 시스템 Keychain이 아닌 Mac의 앱 지원 폴더에 저장됩니다. 구성한 제공자 요청을 인증하는 데 쓰이며 Vault 서버에 업로드되지 않습니다. 조사는 정리된 공개 주제를 선택한 제공자에 보내며 비공개 콘텐츠 본문/요약은 보내지 않습니다. 전송 필드는 동의 안내에서 확인하세요. 제공자 사용에는 연결 테스트와 모델 목록 요청도 포함됩니다.

조사 상태에는 대기 요청, 재시도 대기시간, 실패, 당일 토큰 사용량이 표시됩니다. **실패한 주제를 지금 다시 시도**는 가능한 실패를 재시도하며 일일 한도나 동의를 우회하지 않습니다.

## 활동

활동은 활성화된 앱 사용, 웹사이트 방문, 지원되는 **열람 콘텐츠**를 로컬에 기록합니다. 차트는 기록 데이터를 보여 줍니다. 빈 영역이 Mac가 유휴 상태였다는 뜻은 아닙니다.

날짜 범위를 선택하세요. **타임라인**은 시간대별 사용을 보여 주고 **합계**는 기간을 더합니다. **시간 간격**은 각 간격의 사용을 세로 블록으로 묶습니다. **색상**은 클릭 가능한 범례입니다. 출처를 선택해 차트를 해당 출처에 집중하세요. 날짜를 고르면 그날 이후 사용을 봅니다.

### 활동 그룹

선택한 앱과 웹사이트를 Usage에서 함께 보여 줄 그룹을 만드세요. **병합**은 활동 전체에서 구성원에게 하나의 이름과 색을 사용합니다. 활동 그룹은 기록된 사용을 정리하며 차단 그룹/분류기 그룹과 별개입니다. 활동 그룹 편집기에서 **저장**을 명시적으로 누르세요.

### 기록과 보관 기간

**기록**에서 각 범주나 출처의 기록을 켜거나 끄세요. **보관**은 기록 유지 기간을 정하고, **영구**는 자동 만료 없이 보관합니다. 개별 선택은 더 넓은 설정을 따를 수 있습니다. 기록을 끄면 새 기록이 멈추며 기록을 삭제하면 기존 항목이 사라집니다.

플랫폼 피드는 페이지를 열었는지와 관계없이 지원되는 플랫폼 페이지에 표시된 콘텐츠를 수집합니다. **태그 지정 지원** 피드는 기록이 켜져 있을 때 분류기에 데이터를 제공할 수 있습니다. 보관 기간은 수집 콘텐츠를 앱/웹사이트 사용과 별도로 제어합니다. 분류기 그룹을 일시 중지해도 기록 자체는 꺼지지 않습니다.

## 분류기 설정

**태그 패키지 업데이트**는 검증된 태그 패키지 업데이트를 적용할 시점으로 **자동**, **먼저 확인**, **수동**을 선택합니다. 이는 그룹에서 선택한 로컬 모델 다운로드와 별개입니다. **다운로드**를 선택하면 Hugging Face에서 모델 파일을 받습니다. 다운로드 중에는 그룹 진행률/상태와 **취소**를 사용하세요.

설정에서 인터페이스 언어를 선택하세요. 선택한 언어의 작은 Info 버튼에서 필드 설명을 볼 수 있습니다.

## 저장 및 문제 해결

일반적인 Vault 및 분류기 편집은 자동 저장됩니다. 활동 그룹 편집은 **저장**을 사용합니다. 추가, 삭제, 모델 다운로드, 연결 테스트, 모델 목록 가져오기는 명시적인 작업입니다.

태그가 없다면 브라우저 연결, 전체 태그 지정 스위치, 그룹 일시 중지 상태, 플랫폼 기록, 모델 다운로드를 확인하세요. 조사가 실행되지 않으면 동의, 그룹 선택, 제공자 자격 증명, 조사 모델, 조사 상태를 확인하세요. 연결 그룹을 편집할 수 없다면 관련 프로그램을 다시 연결하거나 안내에 따라 동결을 해제하세요.
