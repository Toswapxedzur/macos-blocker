# Mac Vault 사용자 설명서

Mac Vault에는 세 페이지가 있습니다. **Vault**는 네이티브 앱을 차단하고, **Content tagging**은 지원되는 브라우저 콘텐츠에 태그를 지정하며, **Activity**는 기록된 사용 내역을 표시합니다. 브라우저 확장 프로그램은 지원 콘텐츠를 수집하고 브라우저 차단을 적용합니다. 사용하는 브라우저에 설치하고 연결하세요.

## 빠른 시작

1. **Vault**에서 blocking group과 Apps 대상을 추가하고 + 선택기에서 앱을 고릅니다.
2. 차단 동작을 선택하고 그룹을 활성화합니다.
3. **Content tagging**에서 그룹을 만들고 플랫폼을 선택한 뒤 설명이 포함된 태그를 추가합니다.
4. Settings → **AI connections**에서 ChatGPT subscription, OpenAI API, Gemini API 또는 Grok API를 선택합니다. 계정을 연결하거나 키를 입력해 모델을 가져온 다음 그룹에서 connection/model을 선택합니다. 태그 지정을 활성화하고 그룹을 재개합니다.
5. 연결된 브라우저에서 지원 콘텐츠를 엽니다. 태그로 차단을 제어하려면 브라우저 blocking group에 태그 필터를 설정합니다.

## 차단 그룹

**Blocking group**은 차단 정책을 적용합니다. **Content tagging group**은 콘텐츠에 태그를 지정하며 그 자체로 차단하지 않습니다. 그룹을 추가하고 이름을 정한 뒤 **Applies to**에서 대상을 고르고, 차단 시점과 일정 또는 시간 할당량을 설정하고 활성화합니다. 일반 편집은 자동 저장됩니다. 오류는 변경이 수락되지 않았다는 뜻이므로 필드를 수정하고 다시 시도하세요. 그룹을 비활성화하면 설정을 유지하며 정책을 중단합니다. **Delete group**은 삭제합니다. 그룹을 끌어 순서를 바꿉니다. 같은 대상에 여러 그룹이 적용될 수 있으며 한 그룹을 snooze해도 다른 그룹의 차단은 해제되지 않습니다. **Export**는 설정을 복사하고, **Import**는 확인 후 선택한 그룹 설정을 대체합니다.

### 시간 할당량 및 일정

**Block immediately**는 활성 그룹이 일치하고 일정이 활성일 때 적용됩니다. **Block when the time allowance is used**는 할당량이 소진될 때까지 사용을 허용합니다. 할당량은 분, 재설정 간격은 시간 단위로 지정합니다. 롤링 제한은 직전 기간의 사용을 계산합니다. 자정 재설정은 롤링 제한도 현지 자정에 새 기간을 시작합니다. 활성 요일과 선택적 현지 시간대를 한 줄에 하나씩 선택하세요(예: **09:00-12:00**). 시간대 목록이 비어 있으면 선택한 요일 전체에 적용됩니다. 같은 날 시작보다 늦게 끝나야 합니다. 밤을 넘는 일정은 요일별로 나누세요.

### Snooze

각 blocking group에서 snooze를 설정합니다. **Pause blocking**은 지정된 시간 동안 정책을 중지합니다. **Add to the time allowance**는 시간 제한 그룹에 사용 가능한 분을 추가합니다. 사용한 추가 할당량만 snoozed time으로 계산됩니다. 사용하지 않은 추가분은 다음 재설정 시 만료됩니다. 롤링 제한에서는 한 기간 후, 자정 재설정이 활성화된 경우 더 빨리 만료될 수 있습니다. **Activation delay**는 차단을 계속하면서 snooze를 늦춥니다. **Cooldown**은 snooze 종료 후 다음 요청까지의 대기입니다. **Required confirmations**는 확인 단계 수입니다. Freeze 전에 허용한 경우에만 frozen group에서 snooze를 사용할 수 있습니다.

### Freeze 및 PIN

**Freeze**는 일반 편집을 막습니다. 해제에는 5초 간격의 확인 10회, 설정된 대기 시간, 6자리 PIN이 필요합니다. **Wait before unfreezing**은 0–72시간이며 0은 대기 없음입니다. 동결 중에는 대기를 늘리고 PIN이 없으면 추가할 수 있지만 해제 전까지 조건을 완화할 수 없습니다. 삭제에도 남은 대기 시간과 PIN 조건이 적용됩니다.

### 연결된 그룹

**Link**를 사용해 다른 Vault 프로그램에서 명시적으로 고른 그룹을 연결합니다. 이름, 지원되는 정책 설정, 대상, 사용량, freeze 조건을 공유합니다. 각 프로그램은 지원하는 대상 유형을 편집하고 적용합니다. 다른 대상 항목은 연결된 프로그램에서 계속 사용할 수 있습니다. **Unlink**는 그룹과 설정을 유지한 채 연결을 끊습니다. 구성원이 오프라인이면 Mac Vault와 연결된 브라우저를 열어 다시 연결하세요. 로컬 저장 정책은 구성원이 오프라인이어도 적용될 수 있습니다.

## 도움말

필드 옆의 작은 **i**를 클릭하면 설명이 표시됩니다. 바깥을 클릭하거나 Escape를 눌러 닫습니다. 목록은 스크롤 영역 안에 있으며 검색은 항목을 삭제하지 않고 표시 항목을 필터링합니다. 사용자 지정 규칙은 [코드 설명서](../code-manual/ko.md)를 참조하세요. 편집기, 활성화, 로그, 파일 접근 및 API를 설명합니다.

## 네이티브 앱

Apps 대상의 + 선택기에서 설치되었거나 실행 중인 앱을 선택합니다. 다른 폴더에서 앱을 실행한 뒤 선택기를 다시 열어 목록을 새로 고칩니다. **Block every app except these**는 목록을 허용 목록으로 바꿉니다. Mac Vault는 일반 Apple 앱과 브라우저 전체를 차단할 수 있지만 Mac Vault 자체와 같은 bundle identifier를 공유하는 앱은 보호됩니다. 차단된 앱에는 종료 요청을 보냅니다. **Ask a blocked app to quit again every (minutes)**가 재요청 간격을 정합니다. 웹 리디렉션, 페이지 일시 중지, 피드 숨김은 브라우저 확장 기능이 적용하며 네이티브 앱 동작이 아닙니다.

## Content tagging

각 그룹은 지정된 플랫폼의 콘텐츠에 자체 태그 트리와 모델 설정을 사용해 태그를 지정합니다. 각 플랫폼은 한 그룹에 속합니다. 생성 시 선택하며 이후 변경할 수 없습니다. Blocking 일정과 필터는 태그 지정을 제어하지 않습니다. Settings에서 활성화하고 그룹마다 **Pause tagging / Resume tagging**을 따로 사용하세요. **Activity → Recording**에서 플랫폼 피드 기록을 끄면 태그 지정도 중단됩니다.

### 태그와 모델 설정

태그를 만들고 의미를 설명하며 트리에서 부모를 지정하거나 제거합니다. 태그를 끌면 가지를 옮깁니다. 명확한 설명은 모델이 비슷한 태그를 구분하도록 돕습니다. 각 그룹 설정은 독립적입니다. **Minimum confidence**는 예측 태그마다 필요한 증거 수준을 1–5로 지정합니다. 새 그룹은 4(강한 근거)에서 시작합니다. 목표 태그 개수는 없으며 항목에 태그가 없을 수도 있습니다. **Tagging instructions**는 그룹별 선호 사항을 저장합니다. 일반 편집은 자동 저장되고 각 그룹은 명시적으로 선택한 connection, model, reasoning effort를 사용합니다.

### AI connections

Settings에는 ChatGPT subscription, OpenAI API, Gemini API, Grok API가 있습니다. 구독은 Vault 자체 로그인과 대상 요금제를 사용합니다. API 키에는 선택한 제공자의 API 요금과 한도가 적용됩니다. 제공자를 선택하고 공통 드롭다운 바로 아래에 키를 입력합니다. 키 변경은 자동 저장되며 필드를 비우면 키가 삭제됩니다. **Fetch model list**로 모델을 가져온 뒤 Content tagging 또는 custom-rule 그룹에서 모델을 선택하세요. 가져오기만으로 모델이 선택되지는 않습니다.

**Reasoning effort**는 선택된 모델의 추론 수준입니다. 지원되는 경우 Model default, Low, Medium, High를 선택합니다. 새 선택은 Medium에서 시작하고 기존 선택은 저장된 대로 유지됩니다. 높은 수준은 시간과 토큰을 늘릴 수 있습니다. 태그 지정의 웹 검색은 항상 활성화되며 모델이 사용 시점을 결정합니다. 검색 및 구조화된 태그 지정을 지원하는 모델을 선택하세요. 실패하거나 사용할 수 없는 요청도 유효한 캐시 결과를 유지합니다. 새 항목은 **Retry cloud classification**을 선택할 때까지 미해결 상태입니다. Vault는 제공자를 자동 전환하지 않으며 연결마다 재시도 간격과 횟수 제한이 따로 있습니다. 브라우저 확장에서 **+ tag**를 눌러 검색 후 추가하세요. 제거 컨트롤을 사용하거나 태그를 선택한 뒤 Delete를 한 번 눌러 제거합니다. **Untagged**는 태그 없이 완료, **Tagging**은 결과 대기 중을 뜻합니다. 해당 항목에는 사용자의 수정이 우선합니다.

## Activity

Activity는 활성 앱 사용, 웹사이트 방문, 지원되는 **Content viewed**를 로컬에 기록합니다. 차트는 기록된 데이터를 보여 주며 빈 곳이 Mac이 유휴 상태였음을 증명하지는 않습니다. 날짜 범위를 선택합니다. **Timeline**은 하루 중 시간별 사용을, **Totals**는 기간 합계를, **Time interval**은 각 간격의 사용을 세로 블록으로 표시합니다. **Colors**는 클릭 가능한 범례입니다. 소스를 선택해 차트를 좁힙니다. 날짜를 선택하면 그날부터의 사용을 봅니다.

### Activity 그룹

Usage에서 선택한 앱과 웹사이트를 함께 보려면 그룹을 만듭니다. **Merge**는 Activity 전체에서 구성원에게 같은 이름과 색을 적용합니다. Activity 그룹은 기록된 사용을 정리하며 blocking group이나 Content tagging group과 별개입니다. 편집기에서 **Save**를 명시적으로 누릅니다.

### Recording 및 보관

**Recording**에서 카테고리나 개별 소스별 기록을 켜거나 끕니다. **Keep**은 기록 보관 기간, **Forever**는 자동 만료 없음을 뜻합니다. 개별 선택은 상위 설정을 따를 수 있습니다. 기록을 끄면 새 기록이 중단되고 기록 삭제는 저장된 항목을 제거합니다. 플랫폼 피드는 페이지를 열었는지와 관계없이 지원 페이지에 표시된 콘텐츠를 수집합니다. **Tagging supported** 피드는 기록 중 Content tagging에 제공될 수 있습니다. 보관 설정은 앱 및 웹 사용과 별도입니다. 태그 지정 그룹을 일시 중지해도 기록 자체는 중단되지 않습니다.

## Settings

Settings에서 인터페이스 언어를 선택합니다. 선택한 언어의 Info 버튼에서 필드 설명을 볼 수 있습니다.

## 저장 및 문제 해결

일반 Vault 및 Content tagging 편집은 자동 저장됩니다. Activity 그룹 편집에는 **Save**가 필요합니다. 추가, 삭제, 연결 테스트, 모델 목록 가져오기는 명시적 동작입니다. 태그가 없으면 브라우저 연결, 전역 태그 지정 스위치, 그룹 일시 중지, 플랫폼 기록, 선택된 connection/model과 자격 증명을 확인하세요. AI 요청이 실패하면 제공자 사용 한도와 그룹 Log도 확인합니다. 연결 그룹을 편집할 수 없으면 프로그램을 다시 연결하거나 안내에 따라 freeze를 해제하세요.
