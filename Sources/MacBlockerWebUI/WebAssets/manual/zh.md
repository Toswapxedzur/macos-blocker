# Mac Vault 用户手册

Mac Vault 有三个页面：**Vault** 屏蔽原生应用，**分类器**为受支持的浏览器内容打标，**活动**显示已记录的使用情况。浏览器扩展采集受支持的内容并执行浏览器屏蔽。请在所用浏览器中安装并连接扩展。

## 快速开始

1. 在 **Vault** 中添加屏蔽组和应用目标，然后使用 + 选择器选择应用。
2. 选择组的屏蔽行为并启用它。
3. 在**分类器**中创建组，选择平台，并添加标签和说明。
4. 选择本地模型档位，必要时下载模型。在设置中启用打标，并恢复该组。
5. 在已连接的浏览器中打开受支持的内容。如果希望标签控制屏蔽，请在浏览器屏蔽组中配置标签筛选。

## 屏蔽组

**屏蔽组**执行屏蔽策略。**分类器组**为内容分配标签，本身不会屏蔽任何内容。

1. 添加屏蔽组并为其命名。
2. 在**应用于**中选择目标。
3. 选择屏蔽生效的条件，再设置时间安排或可用时长。
4. 启用该组。它的目标共用该组的策略。

常规修改会自动保存。出现错误说明修改未被接受；请纠正字段后重试。停用组会停止执行策略，但保留配置。**删除组**会将其移除。拖动组可调整顺序。多个组可以同时应用于同一目标；暂缓其中一个组不会解除其他组的屏蔽。

**导出**复制组的配置。**导入**会在确认后替换所选组的配置。

### 可用时长和时间安排

**立即屏蔽**会在已启用的组匹配目标且处于生效时间内时执行屏蔽。**可用时长用尽后屏蔽**允许先使用匹配的目标，直至可用时长耗尽。

可用时长以分钟设置，重置间隔以小时设置。滚动限制统计最近一个时间窗口内的使用。午夜重置会在本地午夜开始新周期，也适用于滚动限制。

选择生效的星期几，并可添加本地时间段，每行一个，例如 **09:00-12:00**。时间段列表为空时，在所选日期全天生效。同一日期的结束时间必须晚于开始时间；跨夜安排需拆分到不同日期。

### 暂缓

在每个屏蔽组中配置暂缓。**暂停屏蔽**会在指定时长内暂停该组的策略。**增加可用时长**为有时间限制的组增加可使用的分钟数。只有实际消耗的额外时长才计入暂缓使用时间。未用完的额外时长在下次重置时失效；使用滚动限制时，在一个窗口后失效，若启用了午夜重置，也可能更早失效。

**启动延迟**会推迟暂缓生效，等待期间仍执行屏蔽。**冷却时间**是一次暂缓结束后，再次请求暂缓前必须等待的时间。**所需确认次数**设置确认步骤的数量。冻结组只有在冻结前允许暂缓，才能使用暂缓。

### 冻结和 PIN

**冻结**会阻止常规修改。解冻需要进行十次确认，每次间隔五秒，并满足已设置的等待时长和六位 PIN 条件。**解冻前等待**接受 0–72 小时；0 表示不增加等待时间。

冻结期间可以延长等待时间，也可以在尚未设置 PIN 时添加 PIN。解冻前不能减弱这些条件。删除同样受剩余等待时间和 PIN 限制。

### 关联组

使用**关联**连接其他 Vault 程序中明确选定的组。关联组共享名称、受支持的策略设置、目标、使用量和冻结条件。每个程序编辑并执行它支持的目标类型；其他目标条目仍保留供关联程序使用。解除关联后，各组及其设置都会保留。

若关联成员离线，可能无法编辑。打开 Mac Vault 和关联的浏览器以重新连接。成员离线时，本地已保存的策略仍可能继续执行。

## 获取帮助

点击字段旁的小 **i** 查看说明。点击外部或按 Escape 关闭说明。列表位于可滚动的区域中；滚动列表可查看其他条目。搜索只筛选显示的条目，不会删除条目。

自定义规则有单独的[代码手册](../code-manual/zh.md)，介绍编辑器、规则启用、日志、文件访问和受支持的 API。

## 原生应用

使用应用目标的 + 选择器选择已安装的应用。**屏蔽除此之外的所有应用**将列表用作允许列表。系统应用、浏览器和 Vault 自身不参与原生应用屏蔽。

对于被屏蔽的应用，Vault 会请求它退出。**再次请求被屏蔽应用退出的间隔（分钟）**控制重试。网站重定向、页面暂停和内容隐藏由浏览器扩展执行，不会变成原生应用操作。

## 分类器

分类器组使用自己的标签树和模型设置，为所分配平台的内容打标。每个平台只属于一个组。创建组时选择平台，之后不能更改。屏蔽组的时间安排和筛选不控制打标。

在设置中启用打标。分别使用各组的**暂停打标／恢复打标**。在**活动 → 记录**中关闭某个平台内容的记录，也会停止该平台的打标。

### 标签和模型设置

创建标签、描述含义，并在标签树中设置或移除父标签。拖动标签可以移动其分支。清楚的说明有助于模型区分相似标签。各组的设置相互独立。

- **速度 ↔ 质量**选择本地模型档位。较大的模型使用更多内存；速度和结果取决于 Mac 及其工作负载。下载的模型由各组共享。
- **严格 ↔ 宽泛**设置置信度要求和默认标签数量。
- “更多”中的**最少标签数／最多标签数**替代默认数量。“严格 ↔ 宽泛”仍控制额外标签的置信度。任一字段留空时使用其默认值。
- **打标指令**为该组添加可选指令。

常规分类器修改会自动保存。所选档位必须下载后才能打标。使用同一档位的组共享一个已加载模型；最多同时保留两个已加载档位。

在浏览器扩展中纠正内容标签。点击 **+ 标签**，搜索分类器已有的标签并选择要添加的标签。使用标签的移除控件，或选中它后按一次 Delete，即可移除。**未标记**表示打标已完成但没有标签；**正在打标**表示等待结果。纠正结果会影响后续打标。

## 知识和网络研究

知识在这台 Mac 上保存供本地打标模型使用的简短说明。**内容来源**包括创作者、账号、频道和社区。内容打标时会附带来源说明。**已知术语**在标题出现该术语时应用。

添加来源或术语及其说明；若研究已启用，也可将说明留空以请求研究。创作者建议帮助查找分类器已采集的来源。列表达到六项时，会在其上方直接显示搜索：术语和各平台的内容来源分别提供名称、标识符或说明搜索。编辑说明会影响后续打标；删除来源知识不会阻止后续研究再次创建它。

### 配置研究提供商

1. 打开**设置 → API 密钥和提供商**。
2. 选择提供商类型并点击**添加提供商**。这会创建配置，不会签发 API 密钥。
3. 从提供商获取凭证并输入。对于兼容的自定义端点，还需配置端点和协议字段。
4. 在**网络研究**中选择支持内置网络搜索的提供商。获取模型列表并选择研究模型。使用模型选择器的搜索缩小列表；刷新可重新获取列表。
5. 阅读授权说明并同意。在每个组中选择**开启**、**关闭**或**跟随设置**。

配置缺失时，**设置网络研究…**会带您前往设置。组不能绕过研究授权。**测试连接**只确认测试请求成功，不代表每个模型都支持研究。提供商的测试模型与所选研究模型分别设置。

密钥保存在这台 Mac 上的应用支持文件夹中，不在系统钥匙串中。它们用于向配置的提供商认证请求；Vault 不会将其上传至自己的服务器。研究会向所选提供商发送经过清理的公开主题，而不是私密内容正文或摘要。请阅读授权说明以了解发送的具体字段。提供商使用量还包括连接测试和模型列表请求，并非只有研究。

研究状态显示排队请求、重试冷却时间、失败情况和当天的令牌使用量。**立即重试失败主题**会重试符合条件的失败请求，不会绕过每日额度或授权。

## 活动

活动在本地记录已启用的应用使用、网站访问和受支持的**已查看内容**。图表反映已记录的数据；空白区域不证明 Mac 当时处于空闲状态。

选择日期范围。**时间线**显示一天内各时段的使用；**总计**汇总时长。**时间间隔**将每个间隔内的使用合并为竖直区块。**颜色**是可点击的图例：选择一个来源，使图表聚焦于它。选择日期可查看从该日开始的使用情况。

### 活动组

创建组可以在使用情况中一起显示所选应用和网站。**合并**使成员在整个活动页面中共用名称和颜色。活动组整理已记录的使用情况，与屏蔽组或分类器组不同。活动组编辑器需明确点击**保存**。

### 记录和保留

在**记录**中，分别为每个类别或来源开启或关闭记录。**保留**控制历史保留时长；**永久**表示不会自动到期。单项可以跟随更广泛的设置。关闭记录会停止新增记录；删除历史会移除已记录的条目。

平台内容采集会记录受支持平台页面上显示的内容，无论是否打开。有**支持打标**标记的平台，在记录开启时可以向分类器提供内容。其保留设置独立于应用和网站使用记录。暂停分类器组本身不会关闭记录。

## 设置

在设置中选择界面语言。字段旁的小 Info 按钮会使用所选界面语言提供说明。

## 保存和故障排查

常规 Vault 和分类器修改会自动保存。活动组编辑使用**保存**。添加、删除、下载模型、测试连接和获取模型列表仍需要明确操作。

若没有标签，请检查浏览器连接、全局打标开关、组的暂停状态、平台记录和模型下载。若研究不运行，请检查授权、组的选择、提供商凭证、研究模型和研究状态。若无法编辑关联组，请根据提示重新连接其程序或解冻。
