# Mac Vault 用户手册

Mac Vault 有三个页面：**Vault** 阻止原生应用，**内容标记** 为受支持的浏览器内容添加标签，**活动** 显示记录的使用情况。浏览器扩展会收集受支持的内容并执行浏览器拦截。请在使用的浏览器中安装并连接扩展。

## 快速开始

1. 在 **Vault** 中添加 网站屏蔽组 和 Apps 目标，然后用 + 选择器选择应用。
2. 选择拦截行为并启用组。
3. 在 **内容标记** 中创建组、选择平台并添加带说明的标签。
4. 在 设置 → **AI 连接** 中选择 ChatGPT subscription、OpenAI API、Gemini API 或 Grok API。连接账户或输入密钥并获取模型，然后在组中选择 connection/model。启用 tagging 并恢复该组。
5. 在已连接的浏览器中打开受支持的内容。如果想让标签控制拦截，请在浏览器 网站屏蔽组 中设置 tag filter。

## 拦截组

**网站屏蔽组** 应用拦截策略。**内容标记** 为内容分配标签，本身不会拦截。添加并命名组，在 **应用对象** 中选择目标，设置拦截何时生效并配置时间表或时间额度，然后启用组。常规编辑会自动保存。出现错误表示更改未被接受；请修正字段后重试。禁用组会停止策略但保留配置；**删除分组** 会删除组。拖动组可调整顺序。多个组可作用于同一目标；暂停一个组不会解除另一个组的拦截。**导出** 复制配置；**导入** 确认后替换所选组的配置。

### 时间额度和时间表

**Block immediately** 会在启用组匹配且时间表生效时拦截。**Block when the time allowance is used** 允许使用至额度耗尽。额度以分钟设置，重置间隔以小时设置。滚动限制统计前一个时间窗口内的使用量。午夜重置会在当地午夜开启新周期，滚动限制也适用。选择启用的星期和可选的当地时间段，每行一个，例如 **09:00-12:00**。时间段列表为空表示覆盖所选日期的全天。时间段必须在同一天晚于开始时间结束；跨夜时间表请拆到不同日期。

### 暂停

在每个 网站屏蔽组 中配置 snooze。**Pause blocking** 在暂停时长内挂起该组策略。**Add to the time allowance** 为限时组增加可用分钟数。只有实际使用的额外额度才计为 snoozed time。未使用部分在下次重置时过期；滚动限制下经过一个窗口后过期，若启用了午夜重置也可能更早过期。**Activation delay** 会在继续拦截时延后 snooze。**Cooldown** 是 snooze 结束后再次请求前的等待时间。**Required confirmations** 设置确认步骤数。冻结组只有在冻结前允许的情况下才能 snooze。

### Freeze 和 PIN

**Freeze** 阻止常规编辑。解冻需要十次确认，每次间隔五秒，并满足设定的等待时间和六位 PIN。**Wait before unfreezing** 可设为 0–72 小时；0 表示无需等待。冻结期间可以延长等待时间，也可以在尚无 PIN 时添加 PIN，但解冻前不能降低这些条件。删除也受剩余等待时间和 PIN 限制。

### 链接组

使用 **关联** 连接从其他 Vault 程序中明确选择的组。组之间共享名称、受支持的策略设置、目标、使用量和冻结条件。每个程序只能编辑和执行其支持的目标类型；其他目标仍可供链接的程序使用。**取消关联** 会断开连接，但保留组及其设置。如果某个成员离线，请打开 Mac Vault 和链接的浏览器以重新连接。成员离线时，本地保存的策略仍可能继续应用。

## 获取帮助

点击字段旁的小 **i** 查看说明；点击外部或按 Escape 关闭。列表位于可滚动区域中；搜索只筛选可见条目，不会删除条目。自定义规则请参阅[代码手册](../code-manual/zh.md)，其中说明编辑器、激活、日志、文件访问和 API。

## 原生应用

使用 Apps 目标的 + 选择器选择已安装或正在运行的应用。从其他文件夹启动应用后，重新打开选择器刷新列表。**屏蔽除这里列出的应用以外的所有应用** 会将列表变为允许列表。Mac Vault 可拦截普通 Apple 应用和整个浏览器；Mac Vault 本身及共享同一 bundle identifier 的应用受到保护。被拦截的应用会收到退出请求；**每隔（分钟）再次请求关闭被屏蔽的应用** 控制重试间隔。网站重定向、页面暂停和隐藏 feed 由浏览器扩展执行，不属于原生应用操作。

## 内容标记

每个 内容标记 使用自己的标签树和模型设置为分配平台的内容添加标签。每个平台只能属于一个组；创建时选择，之后不能更改。拦截组的时间表和筛选器不控制 tagging。在 设置 中启用 tagging，并分别使用各组的 **暂停标记 / 继续标记**。在 **活动 → 记录** 中关闭平台 feed 记录也会停止该 feed 的 tagging。

### 标签和模型设置

创建标签、描述含义并在标签树中设置或移除父级。拖动标签可移动其分支。清晰的说明有助于模型区分相似标签。各组设置相互独立。**最低标签置信度** 设置每个预测标签所需的证据等级，范围为 1–5；新组从 4（有力支持）开始。没有目标标签数量，条目也可以没有标签。**标记说明** 保存该组的偏好。常规编辑自动保存；每个组使用明确选择的 connection、model 和 reasoning effort。

### AI 连接

设置 提供 ChatGPT subscription、OpenAI API、Gemini API 和 Grok API。该订阅使用 Vault 自己的登录方式和符合条件的计划。API 密钥按所选提供商的 API 计费和使用限制执行。选择提供商并在共享下拉菜单正下方输入密钥；密钥修改会自动保存，清空字段会删除密钥。选择 **获取模型列表** 获取模型，然后在 内容标记 或 custom-rule 组中选择模型；获取模型不会替你选择。

**推理强度** 控制所选模型的思考程度：支持时可选 Model default、Low、Medium 或 High。新选择从 Medium 开始，已有选择保持保存状态。较高强度可能增加耗时和 token 用量。Tagging 始终启用网页搜索，由模型决定何时使用。请选择支持搜索和结构化 tagging 的模型。请求失败或不可用时会保留有效的缓存结果；新条目会保持未解决，直到选择 **重试云端分类**。Vault 不会自动切换提供商；每个连接有各自的重试间隔和次数上限。在浏览器扩展中点击 **+ tag**，搜索并选择标签以添加；使用移除控件，或选中标签后按一次 Delete 删除。**未标记** 表示 tagging 已完成但没有标签；**正在标记** 表示结果仍在等待。你所做的更正对该条目具有决定性。

## 活动

活动 在本地记录已启用应用的使用情况、网站访问和受支持的 **已查看内容**。图表反映记录的数据；空白不代表 Mac 一定处于空闲状态。选择日期范围。**时间线** 按一天中的时刻显示使用情况；**总计** 汇总时长；**时间间隔** 将每个区间的使用合并为竖直块。**颜色** 是可点击的图例；选择来源以聚焦图表。选择某天可查看从该日起的使用情况。

### 活动 组

创建组，在 Usage 中并排显示所选应用和网站。**Merge** 在整个 活动 中为成员使用同一名称和颜色。活动 组用于整理记录的使用情况，与拦截组和 内容标记 不同。请在编辑器中明确点击 **Save** 保存。

### 记录和保留期限

在 **记录** 中按类别或单个来源启用或关闭记录。**保留** 控制历史记录的保留时长；**永久** 表示不会自动过期。单项选择可以遵循更广泛的设置。关闭记录会停止新增记录；删除历史记录会移除已记录条目。平台 feed 会收集受支持页面上显示的内容，无论页面是否打开。开启记录时，**支持标记** feed 可向 内容标记 提供内容。其保留设置与应用和网站使用情况分开。暂停 tagging 组本身不会关闭记录。

## 设置

在 设置 中选择界面语言。字段说明通过所选语言的 Info 按钮提供。

## 保存和故障排查

Vault 和 内容标记 的常规编辑会自动保存；活动 group 编辑器需要点击 **Save**。添加、删除、连接测试和获取模型列表都是明确操作。如果缺少标签，请检查浏览器连接、全局 tagging 开关、组暂停状态、平台记录、所选 connection/model 和凭据。如果 AI 请求失败，也请检查提供商使用限制和组 Log。如果无法编辑链接组，请重新连接相关程序，或按提示解除冻结。
