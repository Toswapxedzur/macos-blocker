# دليل برمجة Mac Vault

[دليل المستخدم](../manual/ar.md)

## مواصفات القاعدة

المصدر: تعبير دالة واحد `(on, v) => { ... }`. لا يُدعم سوى JavaScript المتزامن وواجهة API أدناه؛ لا مؤقتات أو شبكة أو واجهات نظام أصلية أو وصول إلى صفحات المتصفح. تستخدم القواعد المعتمدة على الوقت `ev.now` والأحداث. تستخدم قواعد Safari دليل برمجة المتصفح وتعمل داخل التطبيق الحاوي الخاص بـ Safari Vault.

- يحفظ التحرير مسودة؛ ويُفعّل **تشغيل** القاعدة ويمكّن المجموعة. لا يمكن تشغيل مجموعة مقفلة. يؤدي المصدر الفارغ إلى إلغاء تحميل القاعدة.
- يستبدل التشغيل الناجح المعالجات واللوحات ويمسح مجموعة حظر التطبيقات الخاصة بهذه المجموعة، مع الإبقاء على `v.state`. يبقي فشل التحويل أو التسجيل القاعدة السابقة؛ وقد يوقفها انتهاء المهلة. يعيد التشغيل تسجيل آخر مصدر مفعّل؛ وتُعاد متغيرات الإغلاق ومجموعات حظر التطبيقات إلى الحالة الأولية.
- قد يهيئ التسجيل الحالة ويسجل المعالجات ويعرض اللوحات ويسجل رسائل. يجب وضع إجراءات التطبيقات/الملفات وإرسال الأحداث في المعالجات؛ ويُهمل طابورها عند التسجيل.
- يمنع التعطيل المعالجات ويرفع اللوحات وحظر التطبيقات. يستأنف التمكين القاعدة المحملة ولوحاتها وحظرها المحتفظ به. يحذف الإجراء **حذف** معالجاتها وحالتها وآثارها. لا يعاد فتح التطبيقات التي أُنهيت سابقًا؛ ولا يُتراجع عن كتابة الملفات.
- لا تقتصر الأحداث على أهداف المجموعة العادية؛ اختر التطبيقات داخل القاعدة. تُصف الإجراءات ثم تطبق بعد إرسال الحدث. يوقف الاستثناء ذلك المعالج دون التراجع عن حالته أو إجراءاته؛ وقد تواصل المعالجات اللاحقة. لا توجد أحداث نتائج إلا لإجراءات الملفات.

## واجهة API

- `on(type, handler)` ← قيمة منطقية. يسجل `handler(ev)`؛ وتعمل عدة معالجات حسب ترتيب التسجيل. تشير القيمة false إلى وسيطات غير صالحة أو بلوغ حد المعالجات. `ev = { type: string, now: number, data }`؛ و`now` هو وقت Unix بالمللي ثانية.
- `v.state`: كائن JSON قابل للتغيير، يُحفظ بعد إرسال الحدث. هيّئ الحقول المفقودة بدل الكتابة فوق الحالة الموجودة. تعيين قيمة ليست كائنًا أو كانت مصفوفة يعيدها إلى `{}`؛ ولا تُحفظ التحديثات غير القابلة للتسلسل أو الكبيرة جدًا.
- `v.log(...values)`: المصدر الوحيد لسجل هذه المجموعة. السجلات/المسح مستقلة لكل مجموعة. تظهر أخطاء التحميل في حالة التشغيل؛ ولا تملأ تشخيصات المعالجات السجل.
- `v.emit(type, data)`: يضع نسخة JSON من `data` في طابور معالجات المجموعة بعد الحدث الحالي، مع `now` جديد؛ وليس استدعاءً متزامنًا.
- `v.panel(id, spec)`: يستبدل لوحة المجموعة العائمة المسماة؛ تزيل `spec` الفارغة اللوحة. راجع قسم اللوحات.
- `v.file(op, path, payload?)` ← سلسلة معرّف طلب. راجع قسم الملفات.
- `v.block(appId, on)`: تحافظ true على حظر تطبيق، وتزيل false حظر هذه المجموعة. تتجمع عمليات الحظر عبر المجموعات المفعّلة؛ ولا يمكن لهذا الاستدعاء إلغاء هدف مجموعة أخرى. يطلب الحظر إنهاءً عاديًا ويعيد المحاولة وفق فترة الإعدادات؛ ولا يمنع بدء العملية ولا يضمن قبول التطبيق لأمر Quit.
- `v.quit(appId)`: طلب إنهاء عادي واحد يخضع لسياسة الحماية وإعادة المحاولة نفسها؛ دون حظر مستمر.
- `v.open(appId)`: يطلب من macOS فتح تطبيق مثبت؛ بلا رد نجاح.

تعيد الاستدعاءات الأخرى `undefined`. معرّفات التطبيقات هي معرّفات الحزم (مثل `com.valvesoftware.steam`) ومتاحة في الأحداث. تتجاهل عمليات Block/Quit معرّفات `com.apple.*` والمتصفحات وVault ومساعديه والمعرّفات الفارغة. تنتمي معرّفات اللوحة والحالة إلى مجموعة واحدة، لا إلى اسم عرضها.

## الأحداث

توضح صياغة الحمولة أدناه الأنواع؛ وليست شيفرة قابلة للتنفيذ. تشير `?` إلى حقول اختيارية.

```text
tick (~1 second): { frontmost: App | null, running: App[] }
app: { kind: "launch" | "quit" | "focus" | "blur" | "hide" | "unhide",
       appId: string, name: string, previousAppId?: string | null }
snooze: {}
panel: { panelId: string, controlId: string, eventName: string,
         value: string, values: { [controlId: string]: string } }
file: see Files
App = { appId: string, name: string }
```

- حدث `tick` تقريبي؛ استخدم الطوابع الزمنية لا عدد النبضات. يشمل Running عمليات `.app` المرصودة في المقدمة أو شريط القوائم أو الخلفية ذات معرّفات الحزم؛ لا يشمل كل عمليات Unix. قد تكون Frontmost فارغة أو ذات معرّف تطبيق فارغ.
- يبلغ `app` عن تغييرات دورة الحياة المرصودة قبل حدث `tick` لذلك النبض. يتضمن focus وحده `previousAppId` (null إن كان مجهولًا). الأسماء أسماء عرض وليست معرّفات ثابتة.
- يعني `snooze` أن زر التأجيل في المجموعة ضُغط. لا يطبق إيقافًا مؤقتًا من تلقاء نفسه.
- تستهدف ردود الملفات المجموعة الطالبة. طابق `requestId` وتحقق من `ok` وحدد مهلة باستخدام النبضات: قد تضيع الردود إذا أعيد تحميل القاعدة أو عُطلت. قد تتكرر معرّفات الطلبات بعد التشغيل؛ والطلبات المعلقة ليست أعمالًا دائمة.

## اللوحات

```text
spec = { title?: string, description?: string, controls?: Control[],
         position?: "top-left" | "top-right" | "bottom-left" | "bottom-right" | "center",
         width?: "small" | "medium" | "large" | number }
Control = { id?: string, type?: string, label?: string, value?, disabled?: boolean,
            ...type-specific fields below }
```

الإعدادات الافتراضية: الموضع أسفل اليمين والعرض 300px؛ الأحجام المسبقة small/medium/large هي 220/280/360px؛ ويتراوح العرض الرقمي بين 180 و520px ويقبل سلاسل البكسل. ترتب اللوحات/الأقسام الأصلية عناصر التحكم عموديًا؛ ولا تؤثر حقول تخطيط المتصفح ومحاذاته ودوره وتركيزه التلقائي وأبعاد عناصر التحكم في العارض الأصلي.

تُطبّع المعرّفات إلى أحرف/أرقام ASCII و`_`/`-` (حد أقصى 80)؛ اختر معرّفات فريدة وثابتة. يصبح معرّف عنصر التحكم المحذوف `control-N`، والنوع المحذوف/المجهول text. تكون النصوص والقوائم المحذوفة فارغة؛ وdisabled يساوي false. يستبدل كل استدعاء المواصفات كاملة. تتقدم `value` الصريحة على المدخل المخزن؛ وتستخدم value المحذوفة آخر قيمة حدث ثم تطبيع النوع. توفر الأحداث الأصلية سلاسل؛ حللها إلى نوع القيمة المعلن قبل عرض لوحة محدثة. تُهمل الحقول المجهولة؛ والألوان والخطوط وCSS للوحة من اختصاص Vault.

حقول عناصر التحكم والقيم الأولية:

- `text`: سلسلة `text`، وتساوي label افتراضيًا. `html`: سلسلة `html`، تُنقّى وتُعرض كنص عادي على Mac.
- `button`: `label`، واختياريًا `action: "submit" | "cancel" | "close"`. قيمة النقر هي سلسلة الإجراء أو فارغة. لا ترسل الإجراءات أو تغلق شيئًا تلقائيًا.
- `checkbox`, `toggle`: قيمة `value` منطقية (false افتراضيًا)؛ وقيمة الحدث `"true"`/`"false"`.
- `select`, `radio`: `options: (string | { value: string, label?: string })[]`؛ قيمة نصية (فارغة افتراضيًا). تُزال قيم الخيارات الفارغة؛ وتساوي labels قيمة الخيار افتراضيًا. حدّث قيمة اللوحة ذات النوع الصحيح بعد الاختيار.
- `textInput`, `textarea`: قيمة نصية (فارغة افتراضيًا)؛ و`placeholder` لـ textInput؛ و`rows` لـ textarea من 1 إلى 12 (3 افتراضيًا). يتجاهل textarea الأصلي placeholder.
- `numberInput`, `range`: قيمة رقمية (0 افتراضيًا)، و`min` و`max` و`step` موجب. تُحصر القيم ضمن الحدود؛ وحدود التطبيع غير المحددة −1000000…1000000. إدخال numberInput الأصلي نصي: تحقّق من `Number(event.value)` بنفسك؛ ولا تقيد min/max/step الكتابة. النطاق الأصلي افتراضيًا من 0 إلى 100 وخطوته 1.
- `date`, `time`: إدخال نصي؛ صيغ القيم الأولية `YYYY-MM-DD` و`HH:MM`/`HH:MM:SS` (الصيغ غير الصالحة تصبح فارغة). تحقق من التعديلات بنفسك. `color`: `#RRGGBB` (`#000000` افتراضيًا).
- `pin`: سلسلة أرقام؛ و`length` من 3 إلى 12 (6 افتراضيًا)، و`masked` مفعّل افتراضيًا، و`autoSubmit` معطل. `section`: `text` و`controls`؛ ولا أبناء للأقسام الفرعية عند العمق 3 (عناصر التحكم الجذرية عند العمق 0).

ترسل المدخلات العادية أحداث `change`؛ وترسل الأزرار `click` فقط؛ ويرسل PIN `change` ثم `submit` عند اكتماله إذا كان autoSubmit مفعّلًا. لا توجد أحداث أصلية للتركيب/الإزالة/التركيز/المفاتيح. القيم سلاسل بما فيها الأرقام/القيم المنطقية. تحتوي `values` على قيم الإدخال في اللقطة المعروضة وقد تتأخر عن التعديل المحفز؛ وتحدد `value` ذلك التعديل. احفظها في `v.state` واعرض قيمًا ذات أنواع صحيحة للنماذج الموثوقة. تدمج الأحداث غير الخاصة بالنقر خلال 100ms لكل عنصر؛ فلا تعدها كضغطات مفاتيح.

حدود النص: title/label 240؛ description/text 1000؛ HTML 20000؛ placeholder 500؛ نص الإدخال 2000؛ سلاسل القيم الأخرى 512؛ قيمة/label الخيار 256. تُقتطع الزيادة.

## الملفات

`op`: إحدى القيم `"read"` و`"write"` و`"append"` و`"list"` و`"exists"`. يتطلب **مجلد القواعد المخصصة** في الإعدادات وإذنه.

- `path` نسبي؛ ويفصل `/` المجلدات. تسمح الأجزاء بحروف/أرقام ASCII والمسافات و`_.,@()-`؛ ولا تسمح بنقطة بادئة أو `.`/`..` أو مسار مطلق أو URL. لواحق الملفات `.txt` و`.csv` و`.json` (بلا حساسية لحالة الأحرف). يجب أن يكون مسار List مجلدًا؛ وتعرض `""` الجذر المختار. تُرفض المسارات الخارجة من المجلد المختار، بما فيها المسارات عبر الروابط الرمزية.
- يعيد Read نص UTF-8. يستبدل Write الملف أو ينشئه؛ ويضيف append المحتوى أو ينشئه بلا سطر جديد تلقائي. تُنشأ المجلدات الأب عند الكتابة. تكتب حمولة السلسلة كما هي؛ وتُسلسل حمولات JSON الأخرى؛ وتعني null/المحذوف نصًا فارغًا. تتولى القاعدة تحليل JSON/CSV. الحد الأقصى 1048576 بايت UTF-8.
- يعيد List المجلدات الفرعية الظاهرة مباشرة والملفات المدعومة. الإدخالات: `{ name: string, path: string, kind: "directory" | "file", extension?: string }`؛ ويتضمن extension النقطة للملفات. يعيد Exists قيمة منطقية لمسار ملف مدعوم.

```text
file.data = { requestId: string, op: string, path: string, ok: boolean,
              text: string | null, entries: Entry[] | null,
              exists: boolean | null, error: string }
```

تكون حقول النتائج غير المستخدمة null؛ والنجاح له error فارغ. تشمل الإخفاقات invalid-path وunsupported-file-type وعدم توفر المجلد والملف المفقود والملف الكبير جدًا. تعامل مع error كسلسلة، لا كتعداد ثابت شامل. لا توجد واجهة معاملات؛ نفّذ عمليات القراءة والتعديل والكتابة بالتتابع لكل مسار.

## الحدود

لكل حدث ومجموعة: 256 إجراءً في الطابور و200 استدعاء سجل و64 emit؛ وما زاد يُسقط. لكل قاعدة: 1000 معالج و24 لوحة؛ ولكل قائمة عناصر تحكم 32 إدخالًا ولكل خيار 64 خيارًا؛ وما زاد يُهمل أو يُقتطع. تتوقف سلاسل emit بعد 16 جيلًا. حد الحالة المتسلسلة 65536 حرف JavaScript. أبقِ التسجيل ومجموع معالجات كل حدث دون ثانية؛ وتوقف التجاوزات المتكررة أو انتهاء المهلة الصارمة القاعدة حتى تشغيلها. يحتفظ السجل بـ200 إدخال لكل مجموعة. التوقيت والردود أفضل جهد وليست ضمانات آنية.

## قاعدة كاملة

يُحظر Steam إلا أثناء إيقاف لمدة خمس دقائق يفعّله زر التأجيل أو زر اللوحة:

```javascript
(on, v) => {
  v.state.pauseUntil ??= 0;
  const pause = ev => { v.state.pauseUntil = ev.now + 300000; };
  v.panel("pause", { controls: [{ id: "pause", type: "button", label: "Pause 5 min" }] });
  on("snooze", pause);
  on("panel", ev => {
    if (ev.data.panelId === "pause" && ev.data.controlId === "pause" && ev.data.eventName === "click") pause(ev);
  });
  on("tick", ev => v.block("com.valvesoftware.steam", ev.now >= v.state.pauseUntil));
}
```
