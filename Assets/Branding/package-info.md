# Mac Vault app icon

`mac-vault.svg` and `mac-vault-master.png` are the bright app icon. The release
builder derives the app ICNS from the master PNG. The inverse-name companion
uses the same bright palette. `mac-vault-dark.svg` preserves the exact dark
website source. The visible tile outline is disabled without changing the
current delivered icon's geometry. The canonical bright SVG is mirrored in
`customBlocker/tools/branding/mac-vault-bright.svg`; regenerate on Mini2.
