# Adamancia Vault プライバシー ポリシー

最終更新日: 2026 年 7 月 7 日

Adamancia Vault は、フォーカスとブロックを行うアプリです。このポリシーでは、macOS アプリのリリースについて説明します。

## 概要

Adamancia Vault は、デフォルトでブロック ルールと使用状況を Mac のローカルに維持するように設計されています。このアプリは個人データを販売したり、広告を表示したり、データ ブローカーと個人データを共有したりすることはありません。

## データはローカルに保存されます

アプリは、Mac に次のローカル データを保存する場合があります。

- グループ、スケジュール、タイマー、フリーズ/スヌーズ状態、アプリ設定をブロックします。
- バンドルされた Web インターフェイスからミラーリングされたローカル Web エディター ストレージ。
- macOS アプリをブラウザ拡張機能に接続するときのローカル ブリッジ/リンクの状態。
- macOS ブロッキング エンジンによって使用されるアプリ強制ポリシー ファイル。
- App Store ビルドまたは拡張機能ビルドが App Group を使用する場合の App Group コンテナ データ。

既知のローカル パスは、`RELEASE.md` およびアンインストーラー スクリプトに文書化されています。

## ネットワークの使用

アプリは、ブラウザ拡張機能が Mac アプリに接続できるように、Web アプリ ブリッジのローカル ネットワーク リスナーを開く場合があります。バンドルされた機能 (オプションのアカウントや同期関連機能など) が Adamancia サービスと通信する必要がある場合、アプリはネットワーク リクエストを行うこともあります。

## 分析と広告

macOS アプリにはサードパーティの広告 SDK は含まれていません。機能がオンライン サービスを使用していると明示的に示していない限り、分析を送信すべきではありません。

## オプションのアカウントと同期

リリースでアカウントまたは同期機能が有効になっている場合、それらの機能は、アカウント ID や同期ペイロードなど、その機能を提供するために必要な最小限のデータを送信する場合があります。ダウンロードとローカルのブロックにはアカウントを必要としません。

## 権限

チャネルと有効な機能に応じて、Adamancia Vault は macOS にアクセシビリティ、ネットワーク アクセス、ログイン項目の登録、アプリ グループ アクセスなどの権限を要求する場合があります。これらの権限は、ブロック、アプリの起動、ブリッジ、および永続化機能を提供するために使用されます。

## アンインストール中

DMG には `uninstall.command` が含まれます。確認を求め、実行中のアプリを終了し、可能であればアプリのログイン項目の登録を解除し、`/Applications/AdamanciaVault.app` を削除し、オプションでこのアプリによって作成された既知のファイルのみを削除します。
