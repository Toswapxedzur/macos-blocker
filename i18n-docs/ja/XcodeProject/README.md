# Mac Vault Xcode プロジェクト

`project.yml` は、共有 Swift パッケージを使用する macOS および iOS ターゲット用のチェックインされた XcodeGen 仕様です。

## プロジェクトを生成する

```bash
cd XcodeProject
./generate.sh
open macosBlocker.xcodeproj
```

`project.yml`、ターゲット、資格、またはソース メンバーシップを変更した後に再生成します。生成されたプロジェクト ファイルを正規の構成として使用しないでください。

## 現在のターゲット ファミリ

- `AdamanciaVaultMac` は、`MacBlockerAppFeature` によってサポートされる macOS アプリケーション ターゲットです。
- `macosBlocker` は iOS アプリケーションのターゲットです。
- iOS プロジェクトには、デバイス アクティビティ、シールド構成、およびシールド アクション拡張機能が含まれています。

現在の識別子、展開ターゲット、バージョン フィールド、および機能は、`project.yml` および参照される資格ファイルで定義されます。配布する前に署名環境で確認してください。

## 署名と機能

チームを使用し、配布アカウントに属する識別子をバンドルします。構築しているターゲットに必要な機能を確認します。署名シークレット、プロビジョニング プロファイル、アカウント資格情報をこのリポジトリに追加しないでください。

## まずテストしてください

アーカイブを作成する前に、共有パッケージのテストを実行します。

```bash
cd ..
swift test
```
