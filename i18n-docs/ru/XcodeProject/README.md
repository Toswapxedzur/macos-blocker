# Проект Mac Vault Xcode

`project.yml` — это зарегистрированная спецификация XcodeGen для целей macOS и iOS, которые используют общий пакет Swift.

## Генерируем проект

```bash
cd XcodeProject
./generate.sh
open macosBlocker.xcodeproj
```

Повторно создать после изменения `project.yml`, целей, прав или исходного членства. Не используйте сгенерированные файлы проекта в качестве канонической конфигурации.

## Текущие целевые семьи

- `AdamanciaVaultMac` — это целевое приложение macOS, поддерживаемое `MacBlockerAppFeature`.
- `macosBlocker` — это цель приложения iOS.
- Проект iOS включает расширения Device Activity, Shield Configuration и Shield Action.

Текущие идентификаторы, цели развертывания, поля версии и возможности определены в `project.yml` и соответствующих файлах разрешений. Перед распространением просмотрите их в среде подписи.

## Подписание и возможности

Используйте идентификаторы группы и пакета, принадлежащие учетной записи распространения. Подтвердите возможности, необходимые для создаваемой вами цели. Никогда не добавляйте в этот репозиторий секреты подписи, профили подготовки или учетные данные.

## Сначала проверьте

Запустите тесты общего пакета перед созданием архива:

```bash

```
