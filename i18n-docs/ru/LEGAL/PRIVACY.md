# Политика конфиденциальности хранилища Адамансия

Последнее обновление: 7 июля 2026 г.

Adamancia Vault — приложение для фокусировки и блокировки. Эта политика описывает выпуск приложения macOS.

## Резюме

Adamancia Vault по умолчанию сохраняет правила блокировки и состояние использования локальными для вашего Mac. Приложение не продает персональные данные, не отображает рекламу и не передает персональные данные брокерам данных.

## Данные хранятся локально

Приложение может хранить на вашем Mac следующие локальные данные:

- Блокировка групп, расписаний, таймеров, состояния остановки/отключения и настроек приложения.
- Локальное хранилище веб-редактора, зеркально отображаемое из встроенного веб-интерфейса.
- Состояние локального моста/соединения при подключении приложения macOS к расширениям браузера.
— Файлы политики принудительного применения приложений, используемые механизмом блокировки macOS.
- Данные контейнера группы приложений, когда сборка App Store или сборка расширения используют группу приложений.

Известные локальные пути описаны в `RELEASE.md` и в сценарии удаления.

## Использование сети

Приложение может открыть прослушиватель локальной сети для своего моста веб-приложений, чтобы расширения браузера могли подключаться к приложению Mac. Приложение также может отправлять сетевые запросы, если встроенной функции необходимо взаимодействовать со службами Adamancia, например, дополнительная учетная запись или функции, связанные с синхронизацией.

## Аналитика и реклама

Приложение macOS не включает сторонние рекламные SDK. Он не должен отправлять аналитические данные, если в функции явно не указано, что она использует онлайн-сервис.

## Дополнительные учетные записи и синхронизация

Если в выпуске включены функции учетной записи или синхронизации, эти функции могут отправлять минимальные данные, необходимые для обеспечения этой функции, например идентификационные данные учетной записи и полезные данные синхронизации. Для загрузки и локальной блокировки не требуется учетная запись.

## Разрешения

В зависимости от канала и включенных функций Adamancia Vault может запрашивать у macOS такие разрешения, как доступность, доступ к сети, регистрация элемента входа или доступ к группе приложений. Эти разрешения используются для обеспечения функций блокировки, запуска приложений, моста и сохранения.

## Удаление

DMG включает `uninstall.command`. Он запрашивает подтверждение, завершает работу приложения, если оно запущено, отменяет регистрацию элемента входа в приложение, если это возможно, удаляет `/Applications/AdamanciaVault.app` и, при необходимости, удаляет только известные файлы, созданные этим приложением.

## Контакт

По вопросам конфиденциальности откройте проблему в общедоступном репозитории GitHub или воспользуйтесь контактным каналом, опубликованным на веб-сайте Adamancia Vault.
