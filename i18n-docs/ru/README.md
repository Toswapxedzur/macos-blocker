# Mac Хранилище

Mac Vault — это родной член семейства продуктов Vault для macOS. Он сочетает в себе механизм политики Swift, редактор WebView, встроенные адаптеры инвентаризации и принудительного применения приложений, поддержку пользовательских правил и локальный мостовой концентратор веб-приложений.

Действующий кодекс является источником истины. Ссылка в приложении на английском языке: [Sources/MacBlockerWebUI/WebAssets/manual/en.md](Sources/MacBlockerWebUI/WebAssets/manual/en.md).

## Что реализовано

— Группы по умолчанию для выбранных приложений macOS и пользовательские группы для расширенных правил политики.
- Режимы немедленной блокировки, разрешения и обратного отсчета.
- Расписания, режимы заморозки, потоки повтора, импорт/экспорт и постоянное состояние группы.
- Инвентаризация приложений, состояние разрешений на управление устройствами, встроенные адаптеры принудительного применения и плавающая поверхность статуса.
— Контролируемая среда выполнения политики JavaScript с ведением журнала и проверкой синтаксиса.
— Концентратор моста WebSocket с обратной связью для явно связанных совместимых групп.
- Редактор WebView с той же базовой моделью группы, что и семейство продуктов Vault.

## Развитие

Запустите тесты пакета Swift:

```bash
swift test
```

Пакет включает в себя тесты базовой политики, расписания, специальных правил, мостов, импорта и контроля macOS.

## Проект Xcode

Необязательный проект Xcode создается из [XcodeProject/project.yml](XcodeProject/project.yml):

```bash
cd XcodeProject
./generate.sh
```

Прочтите [XcodeProject/README.md](XcodeProject/README.md) перед настройкой целей подписи или распространения.

## Политика документации

Английские документы остаются каноническими. Пользовательский интерфейс редактора содержит полные каталоги языков, переведенные руководства находятся рядом с `WebAssets/manual/en.md`, а переведенные копии остальных поддерживаемых документов находятся в каталоге `i18n-docs/<locale>/`.

Юридические условия и уведомления о конфиденциальности остаются отдельными юридическими документами; этот README не заменяет их.
