#แมคห้องนิรภัย

Mac Vault เป็นสมาชิก macOS ดั้งเดิมของกลุ่มผลิตภัณฑ์ Vault โดยผสมผสานกลไกนโยบาย Swift, ตัวแก้ไข WebView, รายการแอปพลิเคชันดั้งเดิมและอะแดปเตอร์บังคับใช้, การสนับสนุนกฎที่กำหนดเอง และฮับบริดจ์เว็บแอปในเครื่อง

รหัสปัจจุบันคือที่มาของความจริง ข้อมูลอ้างอิงในแอปภาษาอังกฤษคือ [Sources/MacBlockerWebUI/WebAssets/manual/en.md](Sources/MacBlockerWebUI/WebAssets/manual/en.md)

## สิ่งที่นำไปปฏิบัติ

- กลุ่มเริ่มต้นสำหรับแอปพลิเคชัน macOS ที่เลือกและกลุ่มแบบกำหนดเองสำหรับกฎนโยบายขั้นสูง
- โหมดการบล็อกทันที ค่าเผื่อ และการนับถอยหลัง
- กำหนดการ โหมดหยุดชั่วคราว การเลื่อนการเลื่อน การนำเข้า/ส่งออก และสถานะกลุ่มแบบถาวร
- รายการแอปพลิเคชัน สถานะสิทธิ์การควบคุมอุปกรณ์ อะแดปเตอร์การบังคับใช้ดั้งเดิม และการแสดงสถานะแบบลอย
- รันไทม์นโยบาย JavaScript ที่มีการควบคุมพร้อมการบันทึกและการตรวจสอบไวยากรณ์
- ฮับบริดจ์ WebSocket แบบย้อนกลับสำหรับกลุ่มที่เข้ากันได้ที่เชื่อมโยงอย่างชัดเจน
- เครื่องมือแก้ไข WebView ที่มีโมเดลกลุ่มหลักเดียวกันกับกลุ่มผลิตภัณฑ์ Vault

## การพัฒนา

รันการทดสอบแพ็คเกจ Swift:

```bash
swift test
```

แพ็คเกจประกอบด้วยนโยบายหลัก กำหนดการ กฎที่กำหนดเอง บริดจ์ การนำเข้า และการทดสอบการควบคุม macOS

## โครงการ Xcode

โปรเจ็กต์ Xcode ทางเลือกถูกสร้างขึ้นจาก [XcodeProject/project.yml](XcodeProject/project.yml):

```bash
cd XcodeProject
./generate.sh
```

อ่าน [XcodeProject/README.md](XcodeProject/README.md) ก่อนที่จะกำหนดค่าเป้าหมายการลงนามหรือการเผยแพร่

## นโยบายเอกสาร

เอกสารภาษาอังกฤษยังคงเป็นมาตรฐาน UI ตัวแก้ไขมีแคตตาล็อกสถานที่ที่สมบูรณ์ คู่มือฉบับแปลอยู่ข้างๆ `WebAssets/manual/en.md` และสำเนาที่แปลของเอกสารที่ได้รับการดูแลที่เหลืออยู่อยู่ภายใต้ `i18n-docs/<locale>/`

ข้อกำหนดทางกฎหมายและประกาศความเป็นส่วนตัวยังคงเป็นเอกสารทางกฎหมายที่แยกจากกัน README นี้ไม่ได้แทนที่พวกเขา
