# นโยบายความเป็นส่วนตัวของ Adamancia Vault

อัปเดตล่าสุด: 7 กรกฎาคม 2026

Adamancia Vault เป็นแอปโฟกัสและบล็อก นโยบายนี้อธิบายถึงการเปิดตัวแอป macOS

## สรุป

Adamancia Vault ได้รับการออกแบบมาเพื่อให้กฎการบล็อกและสถานะการใช้งานอยู่ในเครื่อง Mac ของคุณตามค่าเริ่มต้น แอปไม่ขายข้อมูลส่วนบุคคล ไม่แสดงโฆษณา และไม่เปิดเผยข้อมูลส่วนบุคคลกับนายหน้าข้อมูล

## ข้อมูลที่จัดเก็บไว้ในเครื่อง

แอพอาจจัดเก็บข้อมูลในเครื่องต่อไปนี้บน Mac ของคุณ:

- การบล็อกกลุ่ม ตารางเวลา ตัวจับเวลา สถานะหยุด/เลื่อน และการตั้งค่าแอป
- พื้นที่เก็บข้อมูลตัวแก้ไขเว็บในตัวเครื่องมิเรอร์จากเว็บอินเตอร์เฟสที่รวมมา
- สถานะบริดจ์/ลิงก์ในเครื่องเมื่อคุณเชื่อมต่อแอพ macOS กับส่วนขยายเบราว์เซอร์
- ไฟล์นโยบายการบังคับใช้แอปที่ใช้โดยกลไกการบล็อก macOS
- ข้อมูลคอนเทนเนอร์กลุ่มแอพเมื่อรุ่น App Store หรือรุ่นส่วนขยายใช้กลุ่มแอพ

เส้นทางในเครื่องที่รู้จักได้รับการบันทึกไว้ใน `RELEASE.md` และในสคริปต์ตัวถอนการติดตั้ง

## การใช้เครือข่าย

แอพอาจเปิด Listener เครือข่ายท้องถิ่นสำหรับบริดจ์เว็บแอพ เพื่อให้ส่วนขยายเบราว์เซอร์สามารถเชื่อมต่อกับแอพ Mac ได้ แอพยังอาจส่งคำขอเครือข่ายหากคุณสมบัติที่รวมมาจำเป็นต้องสื่อสารกับบริการ Adamancia เช่น บัญชีเสริมหรือคุณสมบัติที่เกี่ยวข้องกับการซิงค์

## การวิเคราะห์และโฆษณา

แอพ macOS ไม่มี SDK โฆษณาของบริษัทอื่น ไม่ควรส่งการวิเคราะห์เว้นแต่คุณลักษณะจะระบุไว้อย่างชัดเจนว่ากำลังใช้บริการออนไลน์

## บัญชีเสริมและการซิงค์

หากเปิดใช้งานคุณสมบัติบัญชีหรือการซิงค์ในรุ่น คุณสมบัติเหล่านั้นอาจส่งข้อมูลขั้นต่ำที่จำเป็นเพื่อให้บริการคุณสมบัตินั้น เช่น ข้อมูลประจำตัวของบัญชีและเพย์โหลดการซิงค์ การดาวน์โหลดและการบล็อกในเครื่องไม่จำเป็นต้องมีบัญชี

## สิทธิ์

ขึ้นอยู่กับช่องทางและคุณสมบัติที่เปิดใช้งาน Adamancia Vault อาจขอสิทธิ์จาก macOS เช่น การเข้าถึง การเข้าถึงเครือข่าย การลงทะเบียนรายการเข้าสู่ระบบ หรือการเข้าถึงกลุ่มแอพ สิทธิ์เหล่านี้ใช้เพื่อมอบฟีเจอร์การบล็อก การเปิดแอป บริดจ์ และการคงอยู่

## กำลังถอนการติดตั้ง

ความเสียหายรวมถึง `uninstall.command` ระบบจะขอการยืนยัน ออกจากแอปหากทำงานอยู่ ยกเลิกการลงทะเบียนรายการเข้าสู่ระบบของแอปเมื่อเป็นไปได้ ลบ `/Applications/AdamanciaVault.app` และเลือกลบเฉพาะไฟล์ที่รู้จักที่สร้างโดยแอปนี้

## ติดต่อ

หากมีคำถามเกี่ยวกับความเป็นส่วนตัว ให้เปิดประเด็นในพื้นที่เก็บข้อมูล GitHub สาธารณะ หรือใช้ช่องทางการติดต่อที่เผยแพร่บนเว็บไซต์ Adamancia Vault
