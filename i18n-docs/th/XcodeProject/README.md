# โครงการ Mac Vault Xcode

`project.yml` เป็นข้อกำหนด XcodeGen ที่เช็คอินสำหรับเป้าหมาย macOS และ iOS ที่ใช้แพ็คเกจ Swift ที่ใช้ร่วมกัน

## สร้างโครงการ

```bash
cd XcodeProject
./generate.sh
open macosBlocker.xcodeproj
```

สร้างใหม่หลังจากเปลี่ยน `project.yml` เป้าหมาย การให้สิทธิ์ หรือการเป็นสมาชิกต้นทาง อย่าใช้ไฟล์โปรเจ็กต์ที่สร้างขึ้นเป็นการกำหนดค่าตามรูปแบบบัญญัติ

## ครอบครัวเป้าหมายปัจจุบัน

- `AdamanciaVaultMac` เป็นเป้าหมายแอปพลิเคชัน macOS ที่สนับสนุนโดย `MacBlockerAppFeature`
- `macosBlocker` เป็นเป้าหมายแอปพลิเคชัน iOS
- โปรเจ็กต์ iOS ประกอบด้วยส่วนขยาย Device Activity, Shield Configuration และ Shield Action

ตัวระบุปัจจุบัน เป้าหมายการปรับใช้ ฟิลด์เวอร์ชัน และความสามารถถูกกำหนดไว้ใน `project.yml` และไฟล์การให้สิทธิ์ที่อ้างอิง ตรวจสอบในสภาพแวดล้อมการลงนามก่อนที่จะแจกจ่าย

## การลงนามและความสามารถ

ใช้ทีมและตัวระบุบันเดิลที่เป็นของบัญชีการแจกจ่าย ยืนยันความสามารถที่ต้องการโดยเป้าหมายที่คุณกำลังสร้าง อย่าเพิ่มความลับในการลงนาม โปรไฟล์การจัดสรร หรือข้อมูลรับรองบัญชีลงในที่เก็บนี้

## ทดสอบก่อนครับ

รันการทดสอบแพ็คเกจที่ใช้ร่วมกันก่อนที่จะสร้างไฟล์เก็บถาวร:

```bash
cd ..
swift test
```
