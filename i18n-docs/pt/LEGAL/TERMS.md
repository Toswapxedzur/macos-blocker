# Termos do Adamancia Vault

Última atualização: 7 de julho de 2026

Estes termos se aplicam à versão do aplicativo macOS do Adamancia Vault.

## Software Alfa

A versão `0.0.2` é um software alfa. Pode ser instável, incompleto ou inadequado para uso crítico. Use-o somente se você se sentir confortável em testar softwares iniciais e relatar problemas.

## Uso pretendido

Adamancia Vault foi concebido como uma ferramenta de autocontrole e produtividade para dispositivos que você possui ou está autorizado a gerenciar. Não o utilize para monitorar, restringir ou interferir no dispositivo de outra pessoa sem permissão clara.

## Sem garantia

O aplicativo é fornecido no estado em que se encontra, sem garantias de qualquer tipo. O bloqueio pode falhar devido a alterações no sistema operacional, falta de permissões, comportamento do navegador, atualizações de aplicativos, bugs ou configuração do usuário.

## Responsabilidade do usuário

Você é responsável por escolher regras, conceder permissões e decidir se o aplicativo é apropriado para seu uso. Não confie no Adamancia Vault como o único controle para situações críticas de segurança, médicas, jurídicas, financeiras ou de emergência.

## App Store e canais de sites

A versão da Mac App Store e a versão DMG do site podem ter recursos diferentes porque os requisitos de sandbox, direitos, regras de revisão, reconhecimento de firma e distribuição da Apple variam de acordo com o canal.

## Dados

Os dados do aplicativo local e os recursos on-line opcionais estão descritos em `LEGAL/PRIVACY.md`.

## Atualizações

Os termos podem mudar conforme o aplicativo evolui. Mantenha cópias permanentes das versões lançadas e das notas de lançamento para que os usuários possam inspecionar o que se aplica a uma versão específica.
