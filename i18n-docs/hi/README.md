# मैक वॉल्ट

मैक वॉल्ट, वॉल्ट उत्पाद परिवार का मूल macOS सदस्य है। यह एक स्विफ्ट नीति इंजन, एक वेबव्यू संपादक, मूल एप्लिकेशन इन्वेंट्री और प्रवर्तन एडाप्टर, कस्टम-नियम समर्थन और एक स्थानीय वेब-ऐप ब्रिज हब को जोड़ती है।

वर्तमान कोड सत्य का स्रोत है. अंग्रेजी इन-ऐप संदर्भ है [Sources/MacBlockerWebUI/WebAssets/manual/en.md](Sources/MacBlockerWebUI/WebAssets/manual/en.md)।

## क्या लागू किया गया है

- चयनित macOS अनुप्रयोगों के लिए डिफ़ॉल्ट समूह और उन्नत नीति नियमों के लिए कस्टम समूह।
- तत्काल, भत्ता, और उलटी गिनती अवरोधन मोड।
- शेड्यूल, फ़्रीज़ मोड, स्नूज़ फ़्लो, आयात/निर्यात और लगातार समूह स्थिति।
- एप्लिकेशन इन्वेंट्री, डिवाइस-नियंत्रण अनुमति स्थिति, मूल प्रवर्तन एडेप्टर और एक फ्लोटिंग स्थिति सतह।
- लॉगिंग और सिंटैक्स जांच के साथ एक नियंत्रित जावास्क्रिप्ट नीति रनटाइम।
- स्पष्ट रूप से जुड़े संगत समूहों के लिए एक लूपबैक वेबसॉकेट ब्रिज हब।
- वॉल्ट उत्पाद परिवार के समान कोर ग्रुप मॉडल वाला एक वेबव्यू संपादक।

##विकास

स्विफ्ट पैकेज परीक्षण चलाएँ:

```bash
swift test
```

पैकेज में मुख्य नीति, शेड्यूल, कस्टम-नियम, ब्रिज, आयात और macOS-नियंत्रण परीक्षण शामिल हैं।

## एक्सकोड प्रोजेक्ट

वैकल्पिक Xcode प्रोजेक्ट [XcodeProject/project.yml](XcodeProject/project.yml) से उत्पन्न होता है:

```bash
cd XcodeProject
./generate.sh
```

हस्ताक्षर या वितरण लक्ष्य कॉन्फ़िगर करने से पहले [XcodeProject/README.md](XcodeProject/README.md) पढ़ें।

## दस्तावेज़ीकरण नीति

अंग्रेजी दस्तावेज़ विहित रहते हैं। संपादक यूआई में संपूर्ण स्थानीय कैटलॉग हैं, अनुवादित मैनुअल `WebAssets/manual/en.md` के पास रहते हैं, और शेष बनाए गए दस्तावेज़ों की अनुवादित प्रतियां `i18n-docs/<locale>/` के अंतर्गत हैं।

कानूनी शर्तें और गोपनीयता नोटिस अलग-अलग कानूनी दस्तावेज़ बने रहते हैं; यह README उन्हें प्रतिस्थापित नहीं करता है.
