# मैक वॉल्ट एक्सकोड प्रोजेक्ट

`project.yml` उन macOS और iOS लक्ष्यों के लिए चेक-इन XcodeGen विनिर्देश है जो साझा स्विफ्ट पैकेज का उपयोग करते हैं।

## प्रोजेक्ट तैयार करें

```bash
cd XcodeProject
./generate.sh
open macosBlocker.xcodeproj
```

`project.yml`, लक्ष्य, पात्रता, या स्रोत सदस्यता बदलने के बाद पुन: उत्पन्न करें। जेनरेट की गई प्रोजेक्ट फ़ाइलों को कैनोनिकल कॉन्फ़िगरेशन के रूप में उपयोग न करें।

## वर्तमान लक्ष्य परिवार

- `AdamanciaVaultMac` `MacBlockerAppFeature` द्वारा समर्थित macOS एप्लिकेशन लक्ष्य है।
- `macosBlocker` iOS एप्लिकेशन लक्ष्य है।
- iOS प्रोजेक्ट में डिवाइस एक्टिविटी, शील्ड कॉन्फ़िगरेशन और शील्ड एक्शन एक्सटेंशन शामिल हैं।

वर्तमान पहचानकर्ता, परिनियोजन लक्ष्य, संस्करण फ़ील्ड और क्षमताएं `project.yml` और संदर्भित पात्रता फ़ाइलों में परिभाषित हैं। वितरण से पहले हस्ताक्षरित वातावरण में उनकी समीक्षा करें।

## हस्ताक्षर और क्षमताएं

वितरण खाते से संबंधित टीम और बंडल पहचानकर्ताओं का उपयोग करें। आप जिस लक्ष्य का निर्माण कर रहे हैं उसके लिए आवश्यक क्षमताओं की पुष्टि करें। इस रिपॉजिटरी में कभी भी साइनिंग सीक्रेट्स, प्रोविजनिंग प्रोफाइल या अकाउंट क्रेडेंशियल न जोड़ें।

## पहले परीक्षण करें

संग्रह बनाने से पहले साझा पैकेज परीक्षण चलाएँ:

```bash
cd ..
swift test
```
