# ম্যাক ভল্ট এক্সকোড প্রকল্প

`project.yml` হল macOS এবং iOS টার্গেটের জন্য চেক-ইন XcodeGen স্পেসিফিকেশন যা শেয়ার করা সুইফট প্যাকেজ ব্যবহার করে।

## প্রকল্প তৈরি করুন

```bash
cd XcodeProject
./generate.sh
open macosBlocker.xcodeproj
```

`project.yml`, লক্ষ্য, এনটাইটেলমেন্ট বা উত্স সদস্যপদ পরিবর্তন করার পরে পুনরায় তৈরি করুন। ক্যানোনিকাল কনফিগারেশন হিসাবে জেনারেট করা প্রকল্প ফাইলগুলি ব্যবহার করবেন না।

## বর্তমান টার্গেট পরিবার

- `AdamanciaVaultMac` হল ম্যাকওএস অ্যাপ্লিকেশন টার্গেট যা `MacBlockerAppFeature` দ্বারা সমর্থিত।
- `macosBlocker` হল iOS অ্যাপ্লিকেশন লক্ষ্য।
- iOS প্রকল্পে ডিভাইস কার্যকলাপ, শিল্ড কনফিগারেশন এবং শিল্ড অ্যাকশন এক্সটেনশন অন্তর্ভুক্ত রয়েছে।

বর্তমান শনাক্তকারী, স্থাপনার লক্ষ্যমাত্রা, সংস্করণ ক্ষেত্র এবং ক্ষমতাগুলি `project.yml` এবং উল্লেখিত এনটাইটেলমেন্ট ফাইলগুলিতে সংজ্ঞায়িত করা হয়েছে। বিতরণের আগে স্বাক্ষর পরিবেশে তাদের পর্যালোচনা করুন।

## স্বাক্ষর এবং ক্ষমতা

ডিস্ট্রিবিউশন অ্যাকাউন্টের অন্তর্গত একটি দল এবং বান্ডেল শনাক্তকারী ব্যবহার করুন। আপনি যে লক্ষ্যটি তৈরি করছেন তার জন্য প্রয়োজনীয় ক্ষমতা নিশ্চিত করুন। এই সংগ্রহস্থলে সাইনিং সিক্রেট, প্রোভিশনিং প্রোফাইল, বা অ্যাকাউন্টের শংসাপত্র যোগ করবেন না।
