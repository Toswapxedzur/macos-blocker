# ম্যাক ভল্ট

Mac ভল্ট হল ভল্ট পণ্য পরিবারের নেটিভ macOS সদস্য। এটি একটি সুইফট পলিসি ইঞ্জিন, একটি ওয়েবভিউ এডিটর, নেটিভ অ্যাপ্লিকেশন ইনভেন্টরি এবং এনফোর্সমেন্ট অ্যাডাপ্টার, কাস্টম-রুল সাপোর্ট এবং একটি স্থানীয় ওয়েব-অ্যাপ ব্রিজ হাবকে একত্রিত করে।

বর্তমান কোড সত্যের উৎস। ইংরেজি ইন-অ্যাপ রেফারেন্স হল [Sources/MacBlockerWebUI/WebAssets/manual/en.md](Sources/MacBlockerWebUI/WebAssets/manual/en.md)।

## কি বাস্তবায়িত হয়

- নির্বাচিত macOS অ্যাপ্লিকেশনগুলির জন্য ডিফল্ট গোষ্ঠী এবং উন্নত নীতির নিয়মগুলির জন্য কাস্টম গোষ্ঠী৷
- অবিলম্বে, ভাতা, এবং কাউন্টডাউন ব্লকিং মোড।
- সময়সূচী, ফ্রিজ মোড, স্নুজ প্রবাহ, আমদানি/রপ্তানি, এবং স্থায়ী গ্রুপ অবস্থা।
- অ্যাপ্লিকেশন ইনভেন্টরি, ডিভাইস-নিয়ন্ত্রণ অনুমতি স্থিতি, স্থানীয় প্রয়োগকারী অ্যাডাপ্টার এবং একটি ভাসমান অবস্থা পৃষ্ঠ।
- লগিং এবং সিনট্যাক্স চেকিং সহ একটি নিয়ন্ত্রিত জাভাস্ক্রিপ্ট নীতি রানটাইম।
- সুস্পষ্টভাবে লিঙ্কযুক্ত সামঞ্জস্যপূর্ণ গোষ্ঠীগুলির জন্য একটি লুপব্যাক ওয়েবসকেট ব্রিজ হাব৷
- Vault পণ্য পরিবারের মতো একই কোর গ্রুপ মডেল সহ একটি WebView সম্পাদক৷

## উন্নয়ন

সুইফট প্যাকেজ পরীক্ষা চালান:

```bash
swift test
```

প্যাকেজটিতে মূল নীতি, সময়সূচী, কাস্টম-নিয়ম, সেতু, আমদানি এবং ম্যাকোস-নিয়ন্ত্রণ পরীক্ষা অন্তর্ভুক্ত রয়েছে।

## এক্সকোড প্রকল্প

ঐচ্ছিক Xcode প্রকল্পটি [XcodeProject/project.yml](XcodeProject/project.yml) থেকে তৈরি করা হয়েছে:

```bash
cd XcodeProject
./generate.sh
```

সাইনিং বা ডিস্ট্রিবিউশন টার্গেট কনফিগার করার আগে [XcodeProject/README.md](XcodeProject/README.md) পড়ুন।

## ডকুমেন্টেশন নীতি

ইংরেজি নথিগুলি ক্যানোনিকাল থাকে। সম্পাদক UI-এর সম্পূর্ণ লোকেল ক্যাটালগ রয়েছে, `WebAssets/manual/en.md` এর পাশেই অনূদিত ম্যানুয়াল রয়েছে, এবং অবশিষ্ট রক্ষণাবেক্ষণ করা নথিগুলির অনুবাদিত অনুলিপিগুলি `i18n-docs/<locale>/` এর অধীনে রয়েছে।

আইনি শর্তাবলী এবং গোপনীয়তা নোটিশ পৃথক আইনি নথি থেকে যায়; এই README তাদের প্রতিস্থাপন করে না।
