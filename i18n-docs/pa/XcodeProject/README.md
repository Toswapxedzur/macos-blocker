# ਮੈਕ ਵਾਲਟ ਐਕਸਕੋਡ ਪ੍ਰੋਜੈਕਟ

`project.yml` macOS ਅਤੇ iOS ਟੀਚਿਆਂ ਲਈ ਚੈੱਕ-ਇਨ XcodeGen ਨਿਰਧਾਰਨ ਹੈ ਜੋ ਸਾਂਝੇ ਸਵਿਫਟ ਪੈਕੇਜ ਦੀ ਵਰਤੋਂ ਕਰਦੇ ਹਨ।

## ਪ੍ਰੋਜੈਕਟ ਤਿਆਰ ਕਰੋ

```bash
cd XcodeProject
./generate.sh
open macosBlocker.xcodeproj
```

`project.yml`, ਟੀਚਿਆਂ, ਹੱਕਦਾਰਾਂ, ਜਾਂ ਸਰੋਤ ਸਦੱਸਤਾ ਨੂੰ ਬਦਲਣ ਤੋਂ ਬਾਅਦ ਮੁੜ ਪੈਦਾ ਕਰੋ। ਕੈਨੋਨੀਕਲ ਕੌਂਫਿਗਰੇਸ਼ਨ ਦੇ ਤੌਰ 'ਤੇ ਤਿਆਰ ਕੀਤੀਆਂ ਪ੍ਰੋਜੈਕਟ ਫਾਈਲਾਂ ਦੀ ਵਰਤੋਂ ਨਾ ਕਰੋ।

## ਮੌਜੂਦਾ ਨਿਸ਼ਾਨਾ ਪਰਿਵਾਰ

- `AdamanciaVaultMac` `MacBlockerAppFeature` ਦੁਆਰਾ ਸਮਰਥਿਤ ਮੈਕੋਸ ਐਪਲੀਕੇਸ਼ਨ ਟੀਚਾ ਹੈ।
- `macosBlocker` ਆਈਓਐਸ ਐਪਲੀਕੇਸ਼ਨ ਦਾ ਟੀਚਾ ਹੈ।
- iOS ਪ੍ਰੋਜੈਕਟ ਵਿੱਚ ਡਿਵਾਈਸ ਗਤੀਵਿਧੀ, ਸ਼ੀਲਡ ਕੌਂਫਿਗਰੇਸ਼ਨ, ਅਤੇ ਸ਼ੀਲਡ ਐਕਸ਼ਨ ਐਕਸਟੈਂਸ਼ਨ ਸ਼ਾਮਲ ਹਨ।

ਮੌਜੂਦਾ ਪਛਾਣਕਰਤਾ, ਤੈਨਾਤੀ ਟੀਚੇ, ਵਰਜਨ ਖੇਤਰ, ਅਤੇ ਸਮਰੱਥਾ `project.yml` ਅਤੇ ਹਵਾਲਾ ਦਿੱਤੀਆਂ ਇੰਟਾਈਟਲਮੈਂਟ ਫਾਈਲਾਂ ਵਿੱਚ ਪਰਿਭਾਸ਼ਿਤ ਕੀਤੇ ਗਏ ਹਨ। ਵੰਡਣ ਤੋਂ ਪਹਿਲਾਂ ਦਸਤਖਤ ਕਰਨ ਵਾਲੇ ਮਾਹੌਲ ਵਿੱਚ ਉਹਨਾਂ ਦੀ ਸਮੀਖਿਆ ਕਰੋ।

## ਦਸਤਖਤ ਅਤੇ ਸਮਰੱਥਾਵਾਂ

ਇੱਕ ਟੀਮ ਅਤੇ ਬੰਡਲ ਪਛਾਣਕਰਤਾ ਦੀ ਵਰਤੋਂ ਕਰੋ ਜੋ ਕਿ ਵੰਡ ਖਾਤੇ ਨਾਲ ਸਬੰਧਤ ਹਨ। ਤੁਹਾਡੇ ਦੁਆਰਾ ਬਣਾਏ ਜਾ ਰਹੇ ਟੀਚੇ ਦੁਆਰਾ ਲੋੜੀਂਦੀਆਂ ਸਮਰੱਥਾਵਾਂ ਦੀ ਪੁਸ਼ਟੀ ਕਰੋ। ਇਸ ਰਿਪੋਜ਼ਟਰੀ ਵਿੱਚ ਕਦੇ ਵੀ ਦਸਤਖਤ ਕਰਨ ਦੇ ਭੇਦ, ਪ੍ਰੋਵੀਜ਼ਨਿੰਗ ਪ੍ਰੋਫਾਈਲਾਂ, ਜਾਂ ਖਾਤੇ ਦੇ ਪ੍ਰਮਾਣ ਪੱਤਰਾਂ ਨੂੰ ਸ਼ਾਮਲ ਨਾ ਕਰੋ।
