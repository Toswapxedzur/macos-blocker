# ਮੈਕ ਵਾਲਟ

ਮੈਕ ਵਾਲਟ ਵਾਲਟ ਉਤਪਾਦ ਪਰਿਵਾਰ ਦਾ ਮੂਲ macOS ਮੈਂਬਰ ਹੈ। ਇਹ ਇੱਕ ਸਵਿਫਟ ਪਾਲਿਸੀ ਇੰਜਣ, ਇੱਕ WebView ਸੰਪਾਦਕ, ਨੇਟਿਵ ਐਪਲੀਕੇਸ਼ਨ ਇਨਵੈਂਟਰੀ ਅਤੇ ਇਨਫੋਰਸਮੈਂਟ ਅਡਾਪਟਰ, ਕਸਟਮ-ਨਿਯਮ ਸਹਾਇਤਾ, ਅਤੇ ਇੱਕ ਸਥਾਨਕ ਵੈਬ-ਐਪ ਬ੍ਰਿਜ ਹੱਬ ਨੂੰ ਜੋੜਦਾ ਹੈ।

ਮੌਜੂਦਾ ਕੋਡ ਸੱਚ ਦਾ ਸਰੋਤ ਹੈ। ਅੰਗਰੇਜ਼ੀ ਇਨ-ਐਪ ਹਵਾਲਾ ਹੈ [Sources/MacBlockerWebUI/WebAssets/manual/en.md](Sources/MacBlockerWebUI/WebAssets/manual/en.md)।

## ਕੀ ਲਾਗੂ ਹੈ

- ਚੁਣੇ macOS ਐਪਲੀਕੇਸ਼ਨਾਂ ਲਈ ਡਿਫੌਲਟ ਸਮੂਹ ਅਤੇ ਉੱਨਤ ਨੀਤੀ ਨਿਯਮਾਂ ਲਈ ਕਸਟਮ ਸਮੂਹ।
- ਤੁਰੰਤ, ਭੱਤਾ, ਅਤੇ ਕਾਉਂਟਡਾਊਨ ਬਲਾਕਿੰਗ ਮੋਡ।
- ਸਮਾਂ-ਸੂਚੀ, ਫ੍ਰੀਜ਼ ਮੋਡ, ਸਨੂਜ਼ ਫਲੋ, ਆਯਾਤ/ਨਿਰਯਾਤ, ਅਤੇ ਸਥਾਈ ਸਮੂਹ ਸਥਿਤੀ।
- ਐਪਲੀਕੇਸ਼ਨ ਵਸਤੂ ਸੂਚੀ, ਡਿਵਾਈਸ-ਨਿਯੰਤਰਣ ਅਨੁਮਤੀ ਸਥਿਤੀ, ਨੇਟਿਵ ਇਨਫੋਰਸਮੈਂਟ ਅਡਾਪਟਰ, ਅਤੇ ਇੱਕ ਫਲੋਟਿੰਗ ਸਥਿਤੀ ਸਤਹ।
- ਲਾਗਿੰਗ ਅਤੇ ਸਿੰਟੈਕਸ ਜਾਂਚ ਦੇ ਨਾਲ ਇੱਕ ਨਿਯੰਤਰਿਤ JavaScript ਨੀਤੀ ਰਨਟਾਈਮ।
- ਸਪੱਸ਼ਟ ਤੌਰ 'ਤੇ ਲਿੰਕ ਕੀਤੇ ਅਨੁਕੂਲ ਸਮੂਹਾਂ ਲਈ ਇੱਕ ਲੂਪਬੈਕ WebSocket ਬ੍ਰਿਜ ਹੱਬ।
- Vault ਉਤਪਾਦ ਪਰਿਵਾਰ ਦੇ ਸਮਾਨ ਕੋਰ ਗਰੁੱਪ ਮਾਡਲ ਵਾਲਾ ਇੱਕ WebView ਸੰਪਾਦਕ।

## ਵਿਕਾਸ

ਸਵਿਫਟ ਪੈਕੇਜ ਟੈਸਟ ਚਲਾਓ:

```bash
swift test
```

ਪੈਕੇਜ ਵਿੱਚ ਕੋਰ ਨੀਤੀ, ਸਮਾਂ-ਸਾਰਣੀ, ਕਸਟਮ-ਨਿਯਮ, ਬ੍ਰਿਜ, ਆਯਾਤ, ਅਤੇ ਮੈਕੋਸ-ਕੰਟਰੋਲ ਟੈਸਟ ਸ਼ਾਮਲ ਹਨ।

## ਐਕਸਕੋਡ ਪ੍ਰੋਜੈਕਟ

ਵਿਕਲਪਿਕ Xcode ਪ੍ਰੋਜੈਕਟ [XcodeProject/project.yml](XcodeProject/project.yml) ਤੋਂ ਤਿਆਰ ਕੀਤਾ ਗਿਆ ਹੈ:

```bash
cd XcodeProject
./generate.sh
```

ਦਸਤਖਤ ਜਾਂ ਵੰਡ ਟੀਚਿਆਂ ਨੂੰ ਕੌਂਫਿਗਰ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ [XcodeProject/README.md](XcodeProject/README.md) ਪੜ੍ਹੋ।

## ਦਸਤਾਵੇਜ਼ ਨੀਤੀ

ਅੰਗਰੇਜ਼ੀ ਦਸਤਾਵੇਜ਼ ਕੈਨੋਨੀਕਲ ਰਹਿੰਦੇ ਹਨ। ਸੰਪਾਦਕ UI ਕੋਲ ਪੂਰੇ ਲੋਕੇਲ ਕੈਟਾਲਾਗ ਹਨ, ਅਨੁਵਾਦਿਤ ਮੈਨੂਅਲ `WebAssets/manual/en.md` ਦੇ ਨਾਲ ਲਾਈਵ ਹਨ, ਅਤੇ ਬਾਕੀ ਰੱਖੇ ਦਸਤਾਵੇਜ਼ਾਂ ਦੀਆਂ ਅਨੁਵਾਦਿਤ ਕਾਪੀਆਂ `i18n-docs/<locale>/` ਦੇ ਹੇਠਾਂ ਹਨ।

ਕਨੂੰਨੀ ਸ਼ਰਤਾਂ ਅਤੇ ਗੋਪਨੀਯਤਾ ਨੋਟਿਸ ਵੱਖਰੇ ਕਾਨੂੰਨੀ ਦਸਤਾਵੇਜ਼ ਬਣੇ ਰਹਿੰਦੇ ਹਨ; ਇਹ README ਉਹਨਾਂ ਨੂੰ ਨਹੀਂ ਬਦਲਦਾ ਹੈ।
