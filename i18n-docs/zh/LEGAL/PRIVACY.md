# Adamancia Vault 隐私政策

最后更新时间：2026 年 7 月 7 日

Adamancia Vault 是一款聚焦和阻止应用程序。此政策描述了 macOS 应用程序版本。

## 总结

Adamancia Vault 旨在默认情况下将阻止规则和使用状态保留在您的 Mac 本地。该应用程序不出售个人数据，不显示广告，也不与数据经纪人共享个人数据。

## 数据存储在本地

该应用程序可能会在您的 Mac 上存储以下本地数据：

- 阻止组、时间表、计时器、冻结/暂停状态和应用程序设置。
- 从捆绑的 Web 界面镜像的本地 Web 编辑器存储。
- 将 macOS 应用程序连接到浏览器扩展时的本地桥接/链接状态。
- macOS 阻止引擎使用的应用程序强制策略文件。
- 当 App Store 构建或扩展构建使用应用程序组时，应用程序组容器数据。

已知的本地路径记录在 `RELEASE.md` 和卸载程序脚本中。

## 网络使用

该应用程序可能会为其网络应用程序桥打开本地网络侦听器，以便浏览器扩展可以连接到Mac应用程序。如果捆绑功能需要与 Adamancia 服务通信，例如可选帐户或同步相关功能，该应用程序也可能会发出网络请求。

## 分析和广告

macOS 应用程序不包含第三方广告 SDK。除非某个功能明确表示它正在使用在线服务，否则它不应发送分析数据。

## 可选帐户和同步

如果在版本中启用了帐户或同步功能，这些功能可能会发送提供该功能所需的最少数据，例如帐户身份和同步有效负载。下载和本地阻止不需要帐户。

## 权限

根据渠道和启用的功能，Adamancia Vault 可能会向 macOS 请求权限，例如辅助功能、网络访问、登录项注册或应用程序组访问权限。这些权限用于提供阻止、应用程序启动、桥接和持久性功能。

## 卸载

DMG 包括`uninstall.command`。它要求确认，退出应用程序（如果正在运行），在可能的情况下取消注册应用程序的登录项，删除`/Applications/AdamanciaVault.app`，并可选择仅删除此应用程序创建的已知文件。

## 联系方式

对于隐私问题，请在公共 GitHub 存储库中提出问题或使用 Adamancia Vault 网站上发布的联系渠道。
