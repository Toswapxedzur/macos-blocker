# Términos de la bóveda de Adamancia

Última actualización: 7 de julio de 2026

Estos términos se aplican a la versión de la aplicación macOS de Adamancia Vault.

## Software Alfa

La versión `0.0.1` es el software alfa. Puede ser inestable, incompleto o inadecuado para un uso crítico. Úselo sólo si se siente cómodo probando el software en sus primeras etapas e informando problemas.

## Uso previsto

Adamancia Vault está pensado como una herramienta de autocontrol y productividad para dispositivos que posee o está autorizado a administrar. No lo use para monitorear, restringir o interferir con el dispositivo de otra persona sin un permiso claro.

## Sin garantía

La aplicación se proporciona tal cual, sin garantías de ningún tipo. El bloqueo puede fallar debido a cambios en el sistema operativo, permisos faltantes, comportamiento del navegador, actualizaciones de aplicaciones, errores o configuración del usuario.

## Responsabilidad del usuario

Usted es responsable de elegir reglas, otorgar permisos y decidir si la aplicación es apropiada para su uso. No confíe en Adamancia Vault como único control para situaciones críticas de seguridad, médicas, legales, financieras o de emergencia.

## Tienda de aplicaciones y canales del sitio web

La compilación de Mac App Store y la compilación de DMG del sitio web pueden tener diferentes capacidades porque los requisitos de sandboxing, derechos, reglas de revisión, certificación notarial y distribución de Apple difieren según el canal.

## Datos

Los datos de la aplicación local y las funciones en línea opcionales se describen en `LEGAL/PRIVACY.md`.

## Actualizaciones

Los términos pueden cambiar a medida que evoluciona la aplicación. Mantenga copias permanentes de las versiones publicadas y las notas de la versión para que los usuarios puedan inspeccionar lo que se aplicó a una versión específica.
