# ماك فولت

Mac Vault هو عضو macOS الأصلي في عائلة منتجات Vault. فهو يجمع بين محرك سياسة Swift ومحرر WebView ومخزون التطبيقات الأصلي ومحولات التنفيذ ودعم القواعد المخصصة ومركز جسر تطبيق الويب المحلي.

الكود الحالي هو مصدر الحقيقة. المرجع باللغة الإنجليزية داخل التطبيق هو [Sources/MacBlockerWebUI/WebAssets/manual/en.md](Sources/MacBlockerWebUI/WebAssets/manual/en.md).

## ما يتم تنفيذه

- المجموعات الافتراضية لتطبيقات macOS المحددة والمجموعات المخصصة لقواعد السياسة المتقدمة.
- أوضاع الحظر الفوري والبدل والعد التنازلي.
- الجداول الزمنية، وأوضاع التجميد، وتدفقات التأجيل، والاستيراد/التصدير، وحالة المجموعة المستمرة.
- مخزون التطبيق، وحالة إذن التحكم في الجهاز، ومحولات التنفيذ الأصلية، وسطح الحالة العائم.
- وقت تشغيل سياسة JavaScript يتم التحكم فيه مع التحقق من التسجيل وبناء الجملة.
- مركز جسر WebSocket للاسترجاع للمجموعات المتوافقة المرتبطة بشكل صريح.
- محرر WebView بنفس نموذج المجموعة الأساسية مثل عائلة منتجات Vault.

## التطوير

قم بتشغيل اختبارات حزمة Swift:

```bash
swift test
```

تتضمن الحزمة اختبارات السياسة الأساسية والجدول الزمني والقاعدة المخصصة والجسر والاستيراد والتحكم في نظام التشغيل macOS.

## مشروع اكس كود

يتم إنشاء مشروع Xcode الاختياري من [XcodeProject/project.yml](XcodeProject/project.yml):

```bash
cd XcodeProject
./generate.sh
```

اقرأ [XcodeProject/README.md](XcodeProject/README.md) قبل تكوين أهداف التوقيع أو التوزيع.

## سياسة التوثيق

تظل الوثائق الإنجليزية أساسية. تحتوي واجهة مستخدم المحرر على كتالوجات محلية كاملة، وأدلة مترجمة مباشرة بجانب `WebAssets/manual/en.md`، والنسخ المترجمة من المستندات المتبقية التي تم الاحتفاظ بها موجودة ضمن `i18n-docs/<locale>/`.

تظل الشروط القانونية وإشعارات الخصوصية وثائق قانونية منفصلة؛ هذا الملف التمهيدي لا يحل محلها.
