# مشروع Mac Vault Xcode

`project.yml` هي مواصفات XcodeGen التي تم تسجيلها لأهداف macOS وiOS التي تستخدم حزمة Swift المشتركة.

## إنشاء المشروع

```bash
cd XcodeProject
./generate.sh
open macosBlocker.xcodeproj
```

قم بالتجديد بعد تغيير `project.yml` أو الأهداف أو الاستحقاقات أو عضوية المصدر. لا تستخدم ملفات المشروع التي تم إنشاؤها كتكوين أساسي.

## الأسر المستهدفة حاليا

- `AdamanciaVaultMac` هو هدف تطبيق macOS المدعوم بـ `MacBlockerAppFeature`.
- `macosBlocker` هو هدف تطبيق iOS.
- يتضمن مشروع iOS امتدادات نشاط الجهاز، وتكوين الدرع، وإجراء الدرع.

يتم تعريف المعرفات الحالية وأهداف النشر وحقول الإصدار والإمكانات في `project.yml` وملفات الاستحقاق المشار إليها. قم بمراجعتها في بيئة التوقيع قبل التوزيع.

## التوقيع والقدرات

استخدم معرفات الفريق والحزمة التي تنتمي إلى حساب التوزيع. تأكد من الإمكانيات التي يتطلبها الهدف الذي تقوم ببنائه. لا تقم مطلقًا بإضافة أسرار التوقيع أو ملفات تعريف التوفير أو بيانات اعتماد الحساب إلى هذا المستودع.

## الاختبار أولا

قم بتشغيل اختبارات الحزمة المشتركة قبل إنشاء أرشيف:

```bash
cd ..
swift test
```
