# classifier — the Vault Classifier component of Mac Vault (on-device tagging + its page)

> 🤖 **AI protocol:** Read `../package-info.md` (Mac Vault), `../../package-info.md` (group), the group `AGENTS.md`, and `../../misc/project-memory/PROJECT-MEMORY.md` before working here. Update this file when the folder changes. Never delete without owner consent; keep secrets out of git.

- **What:** a **component of Mac Vault, not a product** (owner decision 2026-09-19; it has no version of its own — it arrived with Mac Vault 1.0.0). Mac Vault links the `VaultClassifierApp` library, starts the tagging service at launch (`VaultClassifierPage.shared.start()` in `BlockerAppDelegate`) and shows it as the **Classifier** page of its window (`BlockerMainView`). A local-first macOS Swift package that classifies collected public content (YouTube-first) on-device with llama.cpp, keeps per-video results and user corrections, and pushes tags to the extension for content-based blocking. In-process it joins Mac Vault's local hub as a peer (dev `ws://127.0.0.1:18787`); the standalone shell can still host the hub itself. Optional explicit LLM Assist providers and grounded correction retrieval. **Unreleased**; no default model is bundled.
- **Git:** lives in Mac Vault's repo (`Toswapxedzur/macos-blocker`) under `classifier/`, merged 2026-09-19 with `git subtree add` — all 246 commits and their hashes are preserved. The old `Toswapxedzur/vault-classifier` repo is archived. `git log -- classifier/` covers history after the merge; for earlier history log the old root paths (e.g. `git log -- Sources/VaultClassifierCore`).
- **Build/test/run:** `swift build`, `swift test`; normal dev launch is **`../run-mac-vault.sh`** (the classifier runs inside Mac Vault). `run-vault-classifier.sh` launches the standalone `VaultClassifierShell` window around the same page, for headless rigs (signs with a Developer ID identity so the hub Keychain grant survives rebuilds — close every old instance first, per `../../AGENTS.md`)). `scripts/bundle-llama-runtime.sh` makes an .app self-contained for llama.cpp (used by Mac Vault's `scripts/release/build_app.sh`); `scripts/install-dev-native-host.sh` installs the dev Native Messaging host (both launchers call it); `scripts/package-macapp.sh` packages the standalone shell.
- **Folders:** `Sources/` (`VaultClassifierApp` (a LIBRARY since the merge — public surface is only `VaultClassifierPage`), `VaultClassifierShell` (thin standalone window), `VaultClassifierCore` (pure tagging — imports none of the others), `VaultClassifierBridge` (hub auth + browser-bridge messages), `VaultClassifierResearch` (cloud research execution), `VaultClassifierLLM`, `VaultClassifierEval` (+ `abtest`), `Cllama`, `VaultLocalHubNativeHost`, smoke targets `VaultGroundingSmoke` / `VaultFullLoopSmoke` / `VaultLLMEngineSmoke`), `Tests/`, `native-host/` (native-messaging manifests + entitlements), `docs/architecture/`, `spike/` (throwaway experiment package), `dist/`.
