# Vault Classifier component

Mac Vault owns this component's Classifier page and shared classifier/Activity worker. `Package.swift` builds Core contracts/state/pipeline, provider HTTP/auth, Bridge, App, Activity, the worker and native hub helper. `Tests/` contains Swift regression suites and owned headless web fixtures; `scripts/` contains supporting tools. Root Mac packaging bundles the shared resources.

Production tagging uses one explicitly selected connection/model/reasoning effort per group: ChatGPT subscription, OpenAI API, Gemini API or Grok API. API keys use provider billing and share the existing saved-provider store. Local groups, model downloads, GGUF tiers, resident-engine registry and llama/Metal inference targets were retired on October26,2026. Dormant implementation is preserved in Git history and the independent d80dc8a source archive under `knowledge-dormancy-20261027`; historical model/evaluation documents and datasets describe that archived implementation. They are not active setup instructions.

Classifier state schema8 archives retired Knowledge/dictionary fields before dropping them from active state; schema7 records reasoning effort and retires search-off state; schema6 added API-key selections and drops retired Local groups/Ollama profiles and their group-owned rows while preserving cloud groups, neutral tagging settings, datasets and collected content. Missing connection setup and failed requests leave new items unresolved, retain valid caches and expose Retry. Search tools are always available for tagging; the model chooses when to call them. Model-dependent reasoning choices are validated before dispatch. Group strictness, tag-count overrides and tagging instructions remain.

Tests run on owner-selected Mini2. No public installer or Store publication is authorized. Canonical state and next work: `~/Desktop/agentic/memory/vault-classifier.md`; project bootstrap: `../../misc/project-memory/PROJECT-MEMORY.md` in the group root.

Current runtime has cloud tagging only. Knowledge/dictionary/research code and feature-only tests were retired on 2026-10-27; see `../docs/DORMANT-KNOWLEDGE.md`. `Sources/VaultClassifierCore/DormantKnowledgeArchive.swift` provides the bounded private schema migration, not a runtime adapter.
