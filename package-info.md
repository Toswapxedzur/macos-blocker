# macosBlocker — Mac Vault (native macOS app)

> 🤖 **AI protocol:** Read `../package-info.md` (group), the group `AGENTS.md`, and `../misc/project-memory/PROJECT-MEMORY.md` before working here. Update this file when the folder changes. Never delete without owner consent; keep secrets out of git.

- **What:** the native macOS member of the suite (public name **Mac Vault**): Swift policy engine, WebView editor (the extension's own popup, synced into `Sources/MacBlockerWebUI/WebAssets` by `sync-webui.sh`), app inventory + enforcement adapters, and the **local Vault hub host** (dev `ws://127.0.0.1:18787`, prod 8787) the **Vault Classifier component** (`classifier/` — on-device tagging, shown as the window's **Classifier** page and started at launch so tags keep flowing after the window closes), plus an **MCP HTTP server for agents** (dev port 18788 = the `vault-dev` MCP entry in Claude's config; only reachable while the app runs).
- **MCP tools (2026-09-23):** besides the 10 Vault group tools, the server now serves the classifier's `classifier_state` / `classifier_action` / `classifier_actions` and the browser extension's `extension_state` / `extension_create_group` / `extension_set_group` / `extension_delete_group` / `extension_set_classifier` (`ExtensionMCPTools.swift`: each relays one `browser-request` through `ConnectionHub.sendBrowserRequest` to the connected browser's service worker, which applies the popup's own sanitizers; needs exactly one browser connected or a `browser` argument — a program name such as `chrome`; since 2026-09-25 the hub refuses a second connection from the same browser program with `duplicate-program` — a test rig's Chromium cannot sit beside the owner's Chrome, only one of them is connected at a time) (see `classifier/package-info.md`, "MCP surface"). Bearer token = HMAC of the hub secret (`LocalHubAuthentication.mcpBearerToken`); if a client config holds a stale token the endpoint answers 401 — the client config must be refreshed from the current secret (`~/.claude.json` was refreshed by hand 2026-09-23, backup `~/.claude.json.bak-mcp-token-2026-09-23`).
- **Own git repo:** `Toswapxedzur/macos-blocker`, branch `main`; releases `v0.0.1`, `v0.0.2`, `v0.1.0`, `v0.2.0`, `v1.0.0` (+ `release/` branches; 0.1.0 and 0.2.0 are retroactive milestones, 1.0.0 is the first with the classifier). Version source of truth = `XcodeProject/project.yml` (`MARKETING_VERSION` / `CURRENT_PROJECT_VERSION`).
- **Build/test:** `swift build`, `swift test` (SwiftPM, `Package.swift`; needs Homebrew `llama.cpp` for the classifier's engine; the classifier's own 229 tests run with `swift test --package-path classifier`); dev launch `run-mac-vault.sh` (signs with a Developer ID identity). Release DMG pipeline in `scripts/release/` (see `RELEASE.md`).
- **Folders:** `classifier/` (the Vault Classifier component — a nested SwiftPM package with its own `package-info.md`; merged from the former `vault-classifier` repo with full history), `Sources/` (`MacBlockerCore`, `MacBlockerAppFeature`, `MacBlockerWebUI`, `MacBlockerMacControl`, `MacBlockerPanel`, `MacBlockerScreenTime`), `Tests/`, `XcodeProject/` + `XcodeScaffold/` (app + Safari-extension targets, `SafariWebExtensionHandler.swift`), `Assets/Branding/` (official Mac icon sources), `i18n-docs/`, `LEGAL/`, `dist/` + `release/` (artifacts), `tools/`.
- **Mirror rule:** `Sources/MacBlockerCore/Resources/{rule-core,event-sandbox,group-scopes,group-actions,parental-pin,platform-profiles}.js` must stay byte-identical to customBlocker (a test checks) — refresh with `./sync-webui.sh`.
- **Custom rules (owner 2026-09-27):** bare-bone, no helpers. `RuleRuntime.swift` runs `rule-core.js` + `custom-rule-runtime.js` (Mac Vault's actions: `v.block`/`v.quit`/`v.open` — apps only, never a website) in JSC with a 1.2 s execution limit; `MacEnforcementBridge` sends "tick" {frontmost, running — every app incl. menu-bar/background}, "app" {launch|quit|focus|blur|hide|unhide}, "snooze", "panel", "file", and runs what was last Run (`activeEventSource`); state lives in the store's `cbRuleState`. `SafariCustomRuleBridge` hosts the *browser's* engine for Safari. The WebAssets editor is a synced copy of the customBlocker popup since 2026-09-24 (`./sync-webui.sh`; desktop-only sections are gated by `body.is-native-desktop`) — never hand-edit a synced file; only `chrome-shim.js`, `activity.html`, `icons/` and `manual/` are Mac-specific.
